# OpenAlex Count

A research tool built with Next.js, Convex, WorkOS, and Stripe.

## Getting Started

### Development

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Production Deployment

See [DEPLOYMENT.md](./DEPLOYMENT.md) for complete production setup guide including:

- Docker Compose configuration
- Convex self-hosted setup
- PostgreSQL (Convex-managed)
- Monitoring with Prometheus + Grafana
- Automated deployment with CI/CD
- Backup and disaster recovery

### Key Technologies

- **Next.js 16.1.1** - React framework
- **Convex** - Backend and database
- **WorkOS** - Authentication
- **Stripe** - Billing and subscriptions
- **PostgreSQL 17** - Database (managed by Convex)
- **Prometheus + Grafana** - Monitoring
