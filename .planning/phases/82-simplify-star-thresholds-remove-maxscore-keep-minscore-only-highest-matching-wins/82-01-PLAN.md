<objective>
Refactor the scoring engine to use minScore-only thresholds with highest-matching-wins logic, and update all backend schema/validator/query layers for backward compatibility.

Purpose: Eliminate maxScore complexity from star thresholds. The new model uses only minScore + stars per threshold, sorted by minScore descending with first match winning. This removes gap/overlap concerns entirely.
Output: Updated scoring engine, tests, schema, validators, and query return validators.
</objective>
