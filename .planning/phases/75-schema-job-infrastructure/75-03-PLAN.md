**cancelScreeningJob** - Append to `convex/screening/mutations.ts`:

```typescript
export const cancelScreeningJob = mutation({
  args: { jobId: v.id("screeningJobs") },
  returns: v.null(),
  handler: async (ctx, args) => { ... }
});
```

Handler logic:
1. `requireAuth(ctx)` for authentication
2. `ctx.db.get(args.jobId)` - throw SCREENING_JOB_NOT_FOUND if null or userId mismatch
3. If job.status is terminal ("completed", "cancelled", "failed", "creditsExhausted") -> return null (idempotent no-op)
4. Patch job: `{ status: "cancelled", updatedAt: Date.now() }`
5. If job.workflowId exists: try `workflow.cancel(ctx, job.workflowId)` with try/catch (may fail if already done)
6. Try `screeningPool.cancelAll(ctx)` with try/catch
7. Return null

Note on workpool/workflow cancellation: In this phase, jobs won't have workflowIds yet (workflow start is Phase 77). The try/catch pattern ensures forward-compatibility. The cancelAll() call uses the dedicated screeningPool to avoid cross-cancellation with extraction.
