## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Icon-to-label gaps in badges, inline badge padding |
| sm | 8px | Gap between badge clusters, question list item spacing |
| md | 16px | Card internal padding, dialog section spacing, input field gaps |
| lg | 24px | Section separators within dialog, results card padding |
| xl | 32px | Gap between result paper cards, dialog header/footer padding |
| 2xl | 48px | Empty state vertical spacing, page-level vertical rhythm |
| 3xl | 64px | Results page top padding |

Exceptions:
- **44px minimum touch target** on cancel button, export dropdown trigger, and sidebar footer button (WCAG AAA)
- **12px** (`0.75rem`) border-radius from `--radius` CSS variable (light mode); **10px** (`0.625rem`) in dark mode
- **3px** focus ring width via `focus-visible:ring-[3px]` pattern (established project convention)

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.43 (`leading-[1.43]`) | Question text, evidence quote body, reasoning text, paper metadata |
| Label | 12px (`text-xs`) | 600 (semibold) | 1.33 | Badge text, metric labels, section headers (uppercase tracking-wider), status labels, counter values |
| Heading | 16px (`text-base`) | 600 (semibold) | 1.25 | Card titles (paper titles, dialog titles, metric panel title), question headings |
| Display | 20px (`text-xl`) | 600 (semibold) | 1.2 | Metric values in JobMetricsPanel (papers processed count, latency, cost) |

**Font stack:** `var(--font-outfit), ui-sans-serif, system-ui, ...` (declared in `globals.css` `:root` `--font-sans`).

**Monospace for tabular data:** `tabular-nums` utility on all numeric counters, cost estimates, progress percentages. Geist Mono (`--font-geist-mono`) for any code-like display (trace IDs if shown).

### 60/30/10 Split

| Role | Token | Light Value | Dark Value | Usage |
|------|-------|-------------|------------|-------|
| Dominant (60%) | `--background` | `oklch(0.985 0.002 75)` | `oklch(0.17 0.01 55)` | Page background, dialog backdrop fill |
| Secondary (30%) | `--card` / `--secondary` | `oklch(1 0 0)` / `oklch(0.955 0.01 60)` | `oklch(0.21 0.012 55)` / `oklch(0.25 0.012 55)` | Paper result cards, dialog body, job history items, metric panel background |
| Accent (10%) | `--primary` | `oklch(0.7 0.17 54)` | `oklch(0.72 0.17 54)` | See reserved list below |
| Destructive | `--destructive` | `oklch(0.55 0.22 27)` | `oklch(0.6 0.2 27)` | Failed status badge, error count badge, insufficient credit warning |

### Accent Reserved For (exhaustive list)

The orange primary accent (`--primary`) is reserved for exactly these elements:
1. **"Start Extraction" submit button** in job creation dialog (filled primary variant)
2. **Sidebar footer progress ring** SVG stroke (`oklch(0.70 0.17 54)`)
3. **Active progress bar fill** in job history items and progress view
4. **Focus ring** color (`--ring`) on all focusable elements
5. **"Buy Credits" link button** border/text when balance insufficient

### AI Accent (Violet) -- Extraction-Specific

| Token | Light Value | Dark Value | Reserved For |
|-------|-------------|------------|--------------|
| `--ai-fg` | `oklch(0.45 0.16 293)` | `oklch(0.78 0.12 293)` | "Extracting" status badge text, CriticVerdictBadge "Verified" text |
| `--ai-bg` | `oklch(0.55 0.15 293 / 0.06)` | `oklch(0.65 0.15 293 / 0.08)` | "Extracting" badge background, verified badge background |
| `--ai-border` | `oklch(0.55 0.15 293 / 0.25)` | `oklch(0.65 0.12 293 / 0.20)` | AI surface borders |

### Per-Paper Status Badge Colors (from CONTEXT.md D-08)

| Status | OKLCH Value | Mapped To |
|--------|-------------|-----------|
| Parsing | `oklch(0.55 0.15 250)` | Blue -- data retrieval in progress |
| Extracting | `oklch(0.55 0.15 293)` | Violet (AI accent) -- LLM processing |
| Done | `oklch(0.55 0.15 145)` | Green -- matches ConfidenceBadge "high" hue |
| Failed | `oklch(0.6 0.15 27)` | Red -- matches destructive hue family |

Each badge uses the same pattern as `ConfidenceBadge`: semi-transparent background at `0.15` opacity, border at `0.3` opacity, foreground text at full chroma. Dark mode variants increase lightness by `+0.15` on background and `+0.1` on foreground.

## Animation Contract

All animations use presets from `lib/animation-config.ts`. No ad-hoc spring definitions.

| Interaction | Preset | Specification |
|-------------|--------|---------------|
| Dialog open/close | Built-in shadcn Dialog animation | CSS-based from `tw-animate-css`, no override needed |
| Paper result cards entering viewport | `cardEntrance` + `cardEntranceTransition(index * 0.05)` | `initial: { opacity: 0, y: 10 }`, `animate: { opacity: 1, y: 0 }`, stagger 50ms per card, duration 350ms, ease `[0.25, 0.46, 0.45, 0.94]` |
| Status badge transitions | `subtleSpring` | `stiffness: 350, damping: 30, mass: 0.8` -- used when badge state changes (e.g., parsing to extracting) |
| Question list add/remove | `AnimatePresence mode="popLayout"` + `subtleSpring` | Slide-up fade in, slide-down fade out. `initial: { opacity: 0, height: 0 }`, `animate: { opacity: 1, height: "auto" }` |
| Progress ring stroke | CSS transition | `transition-[stroke-dashoffset] duration-500 ease-out` (matches `ScreeningFooterButton` exactly) |
| `prefers-reduced-motion` | All `motion.div` wrapped with `motion-safe:` prefix | When reduced motion is preferred, all animations resolve to instant state changes with no movement |

## Accessibility Contract (WCAG AAA)

| Requirement | Implementation |
|-------------|---------------|
| Contrast ratio | 7:1 minimum for all text/background pairs. OKLCH tokens validated in both light and dark modes. |
| Focus indicators | `focus-visible:ring-[3px] focus-visible:ring-ring/50` on every interactive element. Ring color inherits `--ring` (orange primary). |
| Touch targets | 44px minimum on cancel button, export triggers, sidebar footer button, dialog close button. |
| Screen readers | `aria-live="polite"` on progress counters and status updates. `role="status"` on progress indicators. `sr-only` labels on icon-only buttons (sidebar footer, export icon). |
| Reduced motion | `motion-safe:` prefix on all Framer Motion animations. CSS transitions use `transition: none` under `prefers-reduced-motion: reduce`. |
| Keyboard navigation | Full Tab/Shift+Tab flow through dialog elements. Escape closes dialog. Enter/Space activates buttons and radio items. Arrow keys navigate radio group. |
| Language | All visible text via `useTranslations("extraction")` -- no hardcoded English strings in components. |
