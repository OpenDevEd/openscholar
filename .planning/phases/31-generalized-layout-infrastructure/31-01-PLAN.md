**1. Add `createSidebarStore` factory to `lib/store.ts`:**

Add a new exported factory function AFTER the existing `useFilterSidebarStore` block (after line ~1149). The factory replicates the existing `FilterSidebarState` pattern but with a configurable persist key:

```typescript
/**
 * Factory for creating independent sidebar collapse stores.
 * Each page gets its own store instance with separate localStorage persistence.
 * Usage: const useMyStore = createSidebarStore('my-persist-key');
 */
export function createSidebarStore(persistKey: string) {
  return create<FilterSidebarState>()(
    persist(
      (set) => ({
        isCollapsed: false,
        _hasHydrated: false,
        setCollapsed: (collapsed) => set({ isCollapsed: collapsed }),
        toggle: () => set((state) => ({ isCollapsed: !state.isCollapsed })),
        setHasHydrated: (state) => set({ _hasHydrated: state }),
      }),
      {
        name: persistKey,
        storage: createJSONStorage(() => localStorage),
        partialize: (state) => ({ isCollapsed: state.isCollapsed }),
        onRehydrateStorage: () => (state) => {
          state?.setHasHydrated(true);
        },
      }
    )
  );
}
```

The `FilterSidebarState` interface is already defined in the file (line ~1116). The factory reuses it. Do NOT modify the existing `useFilterSidebarStore` -- it remains as-is (Phase 32 will refactor SearchSidebar to use the factory).

Also export a generic `createSidebarDimensions` factory:

export function createSidebarDimensions(expandedWidth: number, collapsedWidth: number) {

  });
}
