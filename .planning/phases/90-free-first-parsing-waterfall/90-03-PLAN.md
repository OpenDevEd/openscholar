**1. "OpenAlex metadata resolution" (PARSE-01):**
- Test: "extracts PMCID from ids.pmcid" -- mock OpenAlex returning `ids.pmcid`, mock Europe PMC returning JATS XML. Assert result.parsingSource === "pmc".
- Test: "extracts PMCID from locations array when ids.pmcid absent" -- mock OpenAlex without `ids.pmcid` but with PubMed Central location entry. Assert PMC tier fires.
- Test: "extracts arXiv ID from primary_location landing URL" -- mock OpenAlex with `primary_location.landing_page_url` containing `arxiv.org/abs/2402.08954`. Assert result.parsingSource === "arxiv".
- Test: "extracts arXiv ID from DOI pattern" -- mock OpenAlex with DOI `10.48550/arxiv.2402.08954`. Assert arXiv tier fires.

**2. "PMC JATS XML tier" (PARSE-02):**
- Test: "parses JATS XML body text from Europe PMC" -- mock fetch to return JATS_XML_FIXTURE for the PMC URL. Assert result.bodyText contains "introduction paragraph" and result.parsingSource === "pmc".
- Test: "falls through on PMC 404" -- mock Europe PMC returning 404. Mock arXiv returning HTML. Assert result.parsingSource === "arxiv" (fell through to next tier).

**3. "arXiv HTML tier" (PARSE-03):**
- Test: "parses article body from arXiv HTML" -- mock fetch to return ARXIV_HTML_FIXTURE for arXiv URL. Assert result.bodyText contains "body text of an arXiv paper" and does NOT contain "Navigation to remove" or "console.log". Assert result.parsingSource === "arxiv".
- Test: "falls through on arXiv 404" -- mock arXiv returning 404. Assert falls to next tier.

**4. "unpdf PDF tier" (PARSE-04, PARSE-10):**
- Test: "extracts text from PDF via unpdf" -- mock fetch returning a fake ArrayBuffer. Mock `unpdf.getDocumentProxy` returning `{ numPages: 10 }`. Mock `unpdf.extractText` returning `{ text: "A".repeat(2000), totalPages: 10 }`. Assert result.parsingSource === "unpdf".
- Test: "rejects PDFs with >200 pages" -- mock `getDocumentProxy` returning `{ numPages: 250 }`. Assert falls through to abstract_only (no Gemini fallback for oversized PDFs per PARSE-10).
- Test: "falls through to Gemini when unpdf returns <1500 chars" -- mock extractText returning 500 chars. Mock Gemini generateText returning "Gemini extracted text". Assert result.parsingSource === "gemini".

**5. "Gemini PDF parser tier" (PARSE-05):**
- Test: "uses Gemini when unpdf text is insufficient" -- mock unpdf returning 100 chars. Mock `generateText` from `ai` module returning `{ text: "Full paper text from Gemini" }`. Assert result.parsingSource === "gemini" and bodyText contains "Full paper text from Gemini".

**6. "abstract_only fallback" (PARSE-06):**
- Test: "returns abstract when all tiers fail" -- mock OpenAlex with no PMCID, no arXiv ID, no PDF URL. Assert result.parsingSource === "abstract_only" and result.bodyText === "Test abstract text".
- Test: "returns empty bodyText when no abstract available" -- mock OpenAlex with null abstract_inverted_index. Assert result.parsingSource === "abstract_only" and result.bodyText === "".

**7. "timeout ceilings" (PARSE-09):**
- Test: "respects 20s fetch timeout for OpenAlex" -- mock fetch that checks the signal's timeout. Verify AbortSignal is passed with appropriate timeout.
- Test: "respects 30s timeout for PMC XML parsing" -- verify the PMC tier call is wrapped with 30000ms timeout.

**8. "200-page PDF cap" (PARSE-10):**
- Test: "rejects PDF exceeding 200 pages before extraction" -- mock getDocumentProxy returning numPages: 201. Assert the paper falls through without calling extractText. Assert final result is abstract_only.
