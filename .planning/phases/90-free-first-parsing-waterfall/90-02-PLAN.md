**parseFullText function -- the waterfall chain (D-02, D-03):**

The function body follows this exact sequence:
1. Fetch OpenAlex metadata via `fetchOpenAlexMetadata(doi, openalexId)` with 20s timeout (D-11)
2. Extract PMCID, arXiv ID, PDF URL from metadata
3. If PMCID present: try `parsePmc(pmcId, signal)` with 30s timeout. On success (non-empty text), return `{ bodyText, parsingSource: "pmc" }`. On failure, log warning and fall through.
4. If arXiv ID present: try `parseArxiv(arxivId, signal)` with 30s timeout. On success (non-empty text), return `{ bodyText, parsingSource: "arxiv" }`. On failure, log warning and fall through.
5. If PDF URL present: try `parsePdfWithUnpdf(pdfUrl, signal)` with 60s timeout. Check page count first: if >200 pages, log warning and fall through to abstract (PARSE-10). If unpdf returns >=1500 chars, return `{ bodyText: text, parsingSource: "unpdf" }`. If <1500 chars OR unpdf throws, try `parseWithGemini(pdfUrl, signal)` with 120s timeout (PARSE-05). On Gemini success, return `{ bodyText, parsingSource: "gemini" }`. On Gemini failure, fall through.
6. Abstract-only fallback: call `reconstructAbstract(metadata.abstract_inverted_index)` (import from `../../lib/openalex/reconstruct-abstract`). If abstract empty, return empty string. Return `{ bodyText: abstract, parsingSource: "abstract_only" }`.

```typescript
import { XMLParser } from "fast-xml-parser";

async function parsePmc(pmcId: string, signal: AbortSignal): Promise<string> {
  const url = `https://www.ebi.ac.uk/europepmc/webservices/rest/${pmcId}/fullTextXML`;
  const response = await fetch(url, { signal });
  if (!response.ok) throw new Error(`Europe PMC returned ${response.status} for ${pmcId}`);
  const xml = await response.text();
  const parser = new XMLParser({ ignoreAttributes: true, parseTagValue: false });
  const result = parser.parse(xml);
  const body = result?.article?.body;
  if (!body) throw new Error("No <body> element in JATS XML");
  return extractTextFromJatsBody(body);
}
```

**parseArxiv function (PARSE-03):**
```typescript
import { parseHTML } from "linkedom";

async function parseArxiv(arxivId: string, signal: AbortSignal): Promise<string> {
  const url = `https://arxiv.org/html/${arxivId}`;
  const response = await fetch(url, { signal });
  if (!response.ok) throw new Error(`arXiv HTML returned ${response.status} for ${arxivId}`);
  const html = await response.text();
  const { document } = parseHTML(html);
  const article = document.querySelector("article")
    ?? document.querySelector(".ltx_page_main")
    ?? document.querySelector("main");
  if (!article) throw new Error("No article element found in arXiv HTML");
  for (const el of article.querySelectorAll("script, style, nav, .ltx_bibliography")) {
    el.remove();
  }
  const text = article.textContent?.trim() ?? "";
  if (text.length === 0) throw new Error("Empty text content from arXiv HTML");
  return text;
}
```

**parsePdfWithUnpdf function (PARSE-04, PARSE-10):**
```typescript
import { getDocumentProxy, extractText } from "unpdf";

async function parsePdfWithUnpdf(
  pdfUrl: string,
  signal: AbortSignal
): Promise<{ text: string; totalPages: number }> {
  const response = await fetch(pdfUrl, { signal });
  if (!response.ok) throw new Error(`PDF fetch returned ${response.status}`);
  const buffer = await response.arrayBuffer();
  const pdf = await getDocumentProxy(new Uint8Array(buffer));
  if (pdf.numPages > 200) {
    throw new Error(`PDF has ${pdf.numPages} pages (max 200)`);
  }
  const { totalPages, text } = await extractText(pdf, { mergePages: true });
  return { text: text as string, totalPages };
}
```

**parseWithGemini function (PARSE-05, D-09, D-10):**

```typescript
import { generateText } from "ai";
import { createGoogleGenerativeAI } from "@ai-sdk/google";

async function parseWithGemini(
  pdfUrl: string,
  signal: AbortSignal
): Promise<string> {
  // Fetch PDF data with a separate 20s timeout for the download
  const pdfResponse = await fetch(pdfUrl, { signal: AbortSignal.timeout(20_000) });
  if (!pdfResponse.ok) throw new Error(`PDF fetch returned ${pdfResponse.status}`);
  const pdfData = new Uint8Array(await pdfResponse.arrayBuffer());

  const google = createGoogleGenerativeAI();
  const result = await generateText({
    model: google("gemini-2.5-flash-lite"),
    messages: [
      {
        role: "user",
        content: [
          {
            type: "text",
            text: "Extract all text from this document. Return only the document text, no commentary.",
          },
          {
            type: "file",
            mediaType: "application/pdf",
            data: pdfData,
          },
        ],
      },
    ],
    temperature: 0,
    providerOptions: {
      google: {
        mediaResolution: "MEDIA_RESOLUTION_LOW",
      },
    },
    abortSignal: signal,
  });

  return result.text;
}
```
