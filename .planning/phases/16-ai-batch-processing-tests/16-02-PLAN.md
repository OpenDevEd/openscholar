```typescript
export interface ScreeningQuestionEntry { question: string }
export type ScreeningResponses = Record<string, Record<string, boolean | null>>
```

Function behavior:
1. Initializes empty array for each paper ID
2. For each (paper, question) pair, checks if question exists in `existingResponses[paperId]`
3. If missing, adds question to that paper's missing list
4. Removes papers with no missing questions from result
5. Returns only papers that have at least one missing question
