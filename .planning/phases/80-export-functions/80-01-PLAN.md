<feature>
  <name>Screening Export Format Functions</name>
  <files>lib/screening/export.ts, tests/export-screening.test.ts</files>
  <behavior>
    ## ScreeningExportData type
    - Mirrors the non-null return type of getScreeningResultsForExport
    - Exported for Phase 81 to use as the function input type

    ## exportScreeningToCSV(data: ScreeningExportData): void
    - Headers: Title, Authors, Year, DOI, OpenAlex ID, [question columns from job.questions], Score, Stars, Qualified, Status
    - Question column order derived from job.questions array (NOT from result.answers keys)
    - Answer values: true->"Yes", false->"No", null/undefined->"N/A"
    - Score/stars/qualified: toString() if defined, empty string if undefined
    - CSV escaping: fields with commas/quotes/newlines are quoted, quotes doubled
    - Filename: screening-export-{YYYY-MM-DD}-{status}.csv
    - Calls downloadFile to trigger browser download

    ## exportScreeningToJSON(data: ScreeningExportData): void
    - Envelope: { exportedAt (ISO), job: { status, createdAt (ISO), completedAt (ISO|null), totalPapers, qualifiedPapers, questions, scoringConfig }, results: [...] }
    - Results array: each with openalexId, title, authors ([]  if undefined), publicationYear (null if undefined), doi (null if undefined), status, answers (null if undefined -- distinguish from empty), score (null if undefined), stars (null if undefined), qualified (null if undefined)
    - JSON.stringify with 2-space indentation
    - Filename: screening-export-{YYYY-MM-DD}-{status}.json

    ## exportScreeningToXLSX(data: ScreeningExportData): Promise<void>
    - Results sheet: same columns as CSV, same answer/score formatting
    - Summary sheet sections:
      1. Job Info: status, created date, completed date, total papers, qualified papers
      2. Questions: key + question text list
      3. Scoring Rules: questionKey, yesPoints, noPoints, nullPoints per rule
      4. Star Thresholds: minScore, maxScore, stars per threshold
      5. Statistics: qualified rate (%), average score
    - Dynamic import of exceljs (same pattern as extraction export)
    - Filename: screening-export-{YYYY-MM-DD}-{status}.xlsx

    ## Edge cases (EXP-05)
    - Result with status:"failed", answers:undefined, score:undefined, stars:undefined, qualified:undefined
    - Result with status:"skipped", answers:undefined
    - Result with answers:{q1: null} (AI returned inconclusive)
    - CSV/XLSX: "N/A" for missing answers, empty string for missing score/stars/qualified
    - JSON: null for missing answers/score/stars/qualified (NOT undefined -- must appear in output)
  </behavior>

    1. Define ScreeningExportData interface matching query return shape
    2. Create inline downloadFile helper (avoid cross-module import from extraction)

    4. Implement exportScreeningToCSV with manual CSV building (dynamic question columns)
    5. Implement exportScreeningToJSON with envelope structure
    6. Implement exportScreeningToXLSX with Results + Summary sheets using ExcelJS dynamic import
    7. All three use filename pattern: screening-export-{YYYY-MM-DD}-{status}.{ext}
