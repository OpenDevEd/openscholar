# Phase 95 — UI Design Contract

> Visual and interaction contract for the per-job metrics panel. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Scope

Phase 95 is backend-heavy (structured logging, traceId propagation, error format, SLO persistence). The single UI surface is **OBS-04**: a compact metrics summary panel within the existing extraction job view, displaying four computed values from the `getExtractionJobMetrics` Convex query.

No new pages. No new routes. No new navigation. One component added to an existing view.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 12px | 500 (medium) | 1.4 |
| Heading | 16px | 600 (semibold) | 1.2 |
| Metric Value | 20px | 600 (semibold) | 1.2 |

**Rationale:** Metric values at 20px semibold provide visual weight for the four key numbers. Labels at 12px medium sit below each value as descriptors. Body at 14px is the project standard for detail text. Heading at 16px semibold is used for the panel title "Job Metrics".

Source: Project convention (Outfit variable font from `globals.css`)

## Interaction Contract

### States

| State | What the user sees | Data condition |
|-------|-------------------|----------------|
| Loading | Skeleton placeholders (4 cells, shimmer) | `useQuery` returns `undefined` |
| Empty / No metrics | All values show "--", labels visible | Query returns all zeros (job just started) |
| Partial | Some values populated, others "--" | Job in progress, `averageLatencyMs` may be null |
| Complete | All 4 metrics populated, SLO section visible | Job finished, `citationValidityRate` computed |
| Error | Metrics panel not rendered, parent error boundary handles | Query throws (handled by Phase 94 CRASH-01/CRASH-02 patterns) |
| Unauthorized | Metrics panel not rendered (query returns null) | User does not own this job |

### Metric Formatting Rules

| Metric | Format | Example | Tooltip Detail |
|--------|--------|---------|----------------|
| Papers processed | `{processed} / {total}` | "47 / 120" | "47 completed, 3 failed, 70 remaining" |
| Avg latency | Seconds with 1 decimal | "2.3s" | "Average time per paper across all completed papers" |
| Est. cost | USD with 4 decimals | "$0.0342" | "Estimated from token usage at current OpenRouter rates" |
| Errors | Integer | "3" | "3 papers failed during extraction" |
| Citation validity | Percentage with 1 decimal | "97.2%" | "97.2% of extracted quotes verified by critic pass" |
| Recall on include | Percentage with 1 decimal or "Pending" | "Pending" | "Requires golden set evaluation (Phase 96)" |

### Null Value Display

When a metric value is `null` (not yet computed):
- Display: `--` in muted-foreground color
- Tooltip: explains why unavailable (e.g., "No papers completed yet")

### SLO Threshold Coloring

| Rate | Color | Meaning |
|------|-------|---------|
| >= 0.95 | Success green `oklch(0.55 0.15 145)` | SLO met |
| >= 0.80 and < 0.95 | Warning amber `oklch(0.6 0.12 85)` | SLO at risk |
| < 0.80 | Destructive `var(--destructive)` | SLO violated |

Applied to: Progress bar fill color and percentage text color.

### Responsive Behavior

| Breakpoint | Layout |
|------------|--------|
| < 640px (mobile) | Single column, 4 stacked metric cells |
| >= 640px (sm) | 2x2 grid of metric cells |

### Accessibility

- Each metric cell is a `<div>` with `role="group"` and `aria-label="{label}: {value}"`
- Tooltip triggered on hover AND focus (Radix Tooltip handles this)
- Progress bars have `aria-label="Citation validity rate: {N}%"` and `aria-valuenow={N}`
- Color is never the sole indicator -- text percentages always accompany progress bars
- Reduced-motion: No custom animations in this component (skeleton shimmer respects `prefers-reduced-motion` via Tailwind defaults)

**No primary CTA** -- this phase adds a read-only metrics display, no user actions.

**No destructive actions** -- this phase is purely observational.
