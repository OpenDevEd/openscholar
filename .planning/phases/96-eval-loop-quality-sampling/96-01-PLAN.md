   ```typescript
   async function citationSubstringMatchScorer({
     output,
     expected,
   }: {
     output: string;
     expected?: string;
   }): Promise<{ score: number }> {
     if (!expected || !output) return { score: 0 };
     // Parse the expected JSON (contains expectedSourceSpan + paperBodyText)
     const meta = JSON.parse(expected) as {
       expectedSourceSpan: { startChar: number; endChar: number };
       paperBodyText: string;
     };
     const { startChar, endChar } = meta.expectedSourceSpan;
     const sourceSlice = meta.paperBodyText.slice(startChar, endChar);
     // Parse the output to get evidence_quote
     let evidenceQuote: string;
     try {
       const parsed = JSON.parse(output);
       evidenceQuote = parsed.evidenceQuote ?? "";
     } catch {
       evidenceQuote = output;
     }
     const maxLen = Math.max(evidenceQuote.length, sourceSlice.length);
     const similarity = maxLen === 0 ? 1 : 1 - distance(evidenceQuote, sourceSlice) / maxLen;
     return { score: similarity >= 0.85 ? 1.0 : 0.0 };
   }
   ```

   ```typescript
     });

   });
   ```

```yaml
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4

      - name: Install dependencies
        run: npm ci

      - name: Run eval suite
        run: pnpm vitest run tests/evals/ --reporter=verbose
```

Key design choices:
- `paths` filter per D-10: only triggers on PRs touching extraction code, eval tests, or the prompts module
- `RUN_EVALS: "1"` enables the `describe.skipIf` gate in the eval test
- `OPENAI_BASE_URL` + `OPENAI_API_KEY` routes autoevals Factuality through OpenRouter (avoids needing a separate OpenAI key per Pitfall 2 in RESEARCH.md)
- `timeout-minutes: 15` gives enough time for 20 LLM calls with retries
- Placeholder Clerk/Convex env vars prevent transitive import failures from module resolution
- Uses `npm ci` (not `pnpm install`) matching the existing ci.yml pattern
