<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> Convex startOAuth action | User initiates OAuth. Action generates HMAC-SHA1 signature server-side. Callback URL from client validated by Zotero (must match registered app). |
| Zotero OAuth -> Convex HTTP callback | External redirect carries oauth_token + oauth_verifier. Token verified server-side in completeOAuth against stored tokenSecret. |
| Browser -> Convex disconnect mutation | Auth-gated via `requireCurrentUserId` — only the authenticated user's own connection is deleted. |
| Browser query params (?zotero_connected, ?zotero_error) | User-controllable URL params. Used only for toast display, no security-sensitive state change based on these params alone. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation |
|-----------|----------|-----------|-------------|------------|
| T-104-04 | Spoofing | OAuth callback URL | mitigate | Callback URL constructed from `window.location.origin` (same-origin); Zotero validates against registered app callback URL; token verified server-side via stored `tokenSecret` in `completeOAuth` (convex/zotero/actions.ts line 525) |
| T-104-05 | Tampering | Query param toast | accept | `?zotero_connected=true` only triggers a toast (no state change, no mutation). Worst case: user sees a false success toast. The reactive `getConnectionStatus` query is the authoritative source of truth for UI state — the card reflects actual connection state regardless of params. |
| T-104-06 | Information Disclosure | ZoteroConnectionCard | mitigate | Card displays username and zoteroUserId (non-sensitive public identifiers). Encrypted API key is never returned by `getConnectionStatus` — the query only returns connection metadata, never the key. |
| T-104-07 | Elevation of Privilege | disconnect mutation | mitigate | `disconnect` is gated by `requireCurrentUserId(ctx)` — only deletes the calling user's own connection, cannot delete another user's connection. |
</threat_model>
