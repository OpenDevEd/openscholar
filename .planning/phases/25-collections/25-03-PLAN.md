**1. Create `components/library/collection-manager.tsx`:**

A Dialog-based component for managing collections. Uses the existing shadcn Dialog and Button components.

Props:
```typescript
interface CollectionManagerProps {
  open: boolean;
  onOpenChange: (open: boolean) => void;
}
```

Implementation:
- Fetch collections via `useProtectedQuery(api.library.collections.getCollectionsWithCounts, {})`
- Three modes: list view (default), create mode (input + create button), rename mode (input pre-filled)
- **List mode:** Shows each collection with name, item count badge, and a DropdownMenu with Rename and Delete actions
- **Create mode:** Input field + Create/Cancel buttons. Calls `createCollection` mutation. On success, switch back to list mode and show `toast.success(t("collectionCreated"))`
- **Rename mode:** Input field pre-filled with current name + Save/Cancel buttons. Calls `renameCollection` mutation. On success, switch back to list mode
- **Delete:** Uses `showConfirmation()` with destructive variant. Message: `Delete "{name}"? Papers in this collection will not be removed from your library.` Calls `deleteCollection` mutation on confirm
- Use `useTranslations("libraryPage")` for all strings
- Use lucide icons: FolderPlus (create), Pencil (rename), Trash2 (delete), Folder (list header)
- Include a "Create collection" button at the bottom of the list view

**2. Create `components/library/collection-picker.tsx`:**

A Popover-based multi-select for assigning items to collections.

Props:
```typescript
interface CollectionPickerProps {
  libraryItemId: Id<"libraryItems">;
  trigger: React.ReactNode; // The DropdownMenuItem that opens the picker
}
```

Implementation:
- Fetch all collections via `useProtectedQuery(api.library.collections.getCollectionsWithCounts, {})`
- Fetch item's current collections via `useProtectedQuery(api.library.collections.getItemCollections, { libraryItemId })`
- Render as Popover (from shadcn) with checkboxes for each collection
- Checked = item is in that collection
- Toggle fires `addToCollection` or `removeFromCollection` mutation
- Show collection name + item count badge for each row
- If no collections exist, show a message "No collections yet" with a link/button to create one
- Use `useMutation` for both add and remove operations (fire-and-forget pattern, no await needed for UI responsiveness)
