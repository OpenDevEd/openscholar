## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, remove-button icon gap |
| sm | 8px | Compact element spacing, badge internal padding, drawer list item gap |
| md | 16px | Default element spacing, drawer section padding, Sheet header/footer p-4 |
| lg | 24px | Section padding between per-source groups in drawer |
| xl | 32px | Drawer content top/bottom safe area |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions: 44px minimum touch target for remove buttons on mobile (WCAG AAA)

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 (regular) | 1.43 (20px) |
| Label | 12px (`text-xs`) | 500 (medium) | 1.33 (16px) |
| Heading | 16px (`text-base`) | 600 (semibold) | 1.5 (24px) |
| Display | 20px (`text-lg`) | 600 (semibold) | 1.4 (28px) |

Source: Existing codebase convention. Sheet title uses `font-semibold` (600). Sheet description uses `text-sm` (14px). Badge uses `text-xs` (12px) with `font-medium` (500). These map directly to the roles above.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` / oklch(0.985 0.002 75) | Sheet background, drawer content surface |
| Secondary (30%) | `var(--card)` / oklch(1 0 0) | Paper entry rows in drawer, per-source section headers |
| Accent (10%) | `var(--primary)` / oklch(0.7 0.17 54) | CTA button, sidebar badge count, "already in basket" check indicator |
| Destructive | `var(--destructive)` / oklch(0.55 0.22 27) | Remove-from-basket action only |

Accent reserved for:
- "Review & start extraction" CTA button (`bg-primary text-primary-foreground`)
- Sidebar nav badge pill (orange gradient: `from-[oklch(0.75_0.15_55)] to-[oklch(0.62_0.16_52)]`) -- matches existing NavItem badge pattern
- "Already in basket" check icon tint (`text-primary`)
- Drawer header paper count numeral (`text-primary font-semibold`)

Source badges use `var(--secondary)` with `var(--secondary-foreground)` -- NOT accent. They are informational, not interactive.

## Drawer Layout Specification

### Structure (top to bottom)

```
+------------------------------------------+
| [SheetHeader - sticky]                   |
|   SheetTitle: "Extraction basket"        |
|   SheetDescription: "{count} papers"     |
|     count rendered in text-primary       |
+------------------------------------------+
| [ScrollArea - flex-1 overflow-y-auto]    |
|                                          |
|   [BasketSourceSection: "Library (N)"]   |
|     BasketPaperRow                       |
|     BasketPaperRow                       |
|   [Separator]                            |
|   [BasketSourceSection: "Search (N)"]    |
|     BasketPaperRow                       |
|   [Separator]                            |
|   [BasketSourceSection: "Manual (N)"]    |
|     BasketPaperRow                       |
|                                          |
|   -- OR when empty --                    |
|                                          |
|   [BasketEmptyState]                     |
|                                          |
+------------------------------------------+
| [SheetFooter - sticky]                   |
|   Button: "Review & start extraction"    |
|     variant="default" (primary orange)   |
|     full width, disabled when count=0    |
+------------------------------------------+
```

### BasketPaperRow Layout

```
+------------------------------------------+
| [Title - truncate, text-sm, max 1 line]  |
| [DOI - text-xs text-muted-foreground]    |  [X remove]
| [Badge variant="secondary" - source]     |
+------------------------------------------+
```

- Title: `text-sm font-normal text-foreground truncate` -- max-width constrained by drawer width
- DOI: `text-xs text-muted-foreground truncate` -- show if non-null, hide row if null
- Source badge: `Badge variant="secondary"` with capitalized source label ("Library", "Search", "Manual", "Collection", "Zotero")
- Remove button: `Button variant="ghost" size="icon-xs"` with `X` (Lucide) icon, `text-muted-foreground hover:text-destructive` transition

### BasketSourceSection Layout

- Collapsible header: `button` element, `text-sm font-medium text-foreground`, Lucide `ChevronDown` icon rotates on collapse
- Count shown inline: `text-muted-foreground` after the source label
- Default state: expanded
- Animation: use existing `subtleSpring` from `lib/animation-config.ts` for collapse/expand

## Interaction States

### Drawer Open/Close
- Trigger: `BasketTriggerButton` mounted in app shell (exact mount point decided by Phase 102)
- Open animation: Sheet default slide-in-from-right (500ms)
- Close animation: Sheet default slide-out-to-right (300ms)
- Overlay: `bg-black/50` (Sheet default)

### "Already in Basket" Indicator
- When `useExtractionBasketStore.has(normalizedId)` returns true for a paper in any source list
- Visual: checkbox appears checked with `text-primary` fill, label changes to "In basket" in `text-xs text-muted-foreground`
- Interaction: clicking a paper already in basket opens a tooltip "Already in your extraction basket" -- does NOT remove it (removal is drawer-only per SEL-10)

### Remove Paper
- Click remove button (X) on BasketPaperRow
- Immediate removal from store (no confirmation -- single-paper removal is low-risk and reversible by re-adding)
- Row exits with opacity fade (150ms, `cardEntranceTransition` reversed)
- If source section becomes empty, the section header and separator are removed

### Empty State
- Shown when `count === 0`
- Centered in ScrollArea
- Illustration: Lucide `FlaskConical` icon at 48px, `text-muted-foreground/40`
- Copy below (see Copywriting Contract)

### CTA Button States
- **Enabled** (count > 0): `variant="default"` (orange primary), full width, label "Review & start extraction"
- **Disabled** (count === 0): `disabled` attribute, `opacity-50 pointer-events-none`
- **Navigation**: `router.push("/extraction/new")` then close drawer

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| WCAG AAA contrast (7:1) | All text on `var(--background)` exceeds 7:1. Orange primary on white exceeds 4.5:1 for large text (CTA button at 14px semibold qualifies). Verified via OKLCH perceptual uniformity. |
| Focus indicators | `focus-visible:ring-ring/50 focus-visible:ring-[3px]` on all interactive elements (inherited from shadcn button/sheet defaults) |
| Reduced motion | Sheet respects `prefers-reduced-motion: reduce` via Tailwind `motion-reduce:` utility. Collapse/expand animations disabled. Row removal is instant (no fade). |
| Screen reader | Sheet has `role="dialog"`, `aria-labelledby` (SheetTitle), `aria-describedby` (SheetDescription). Each BasketPaperRow remove button has `aria-label="Remove {title} from basket"`. Source sections use `aria-expanded` on collapse toggle. |
| Touch targets | Remove button minimum 24x24px (icon-xs = 24px). On mobile (`<= 640px`), drawer renders full-width (`w-full` override on SheetContent). |
| Keyboard | Tab order: header close button, source sections (collapsible), paper rows (remove buttons), footer CTA. Escape closes drawer. |
