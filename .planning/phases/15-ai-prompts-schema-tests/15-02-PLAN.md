**encodeQuestionKey / decodeQuestionKey round-trip (AIPR-05):**

Use `it.each` for clean parametric testing:

```typescript
it.each([
  "Is this a randomized trial?",
  "Does the study focus on adults?",
  "Existe-t-il un groupe controle?",  // French with accent
  "这是随机试验吗？",                  // Chinese
  "هل هذه تجربة عشوائية؟",            // Arabic
  "Study with special chars: &=?#/",
  "",                                  // empty string
])("round-trips encodeQuestionKey/decodeQuestionKey: %s", (question) => {
  expect(decodeQuestionKey(encodeQuestionKey(question))).toBe(question);
});
```

**encodeQuestionKey format:**
- Verify `encodeQuestionKey("test")` starts with `"__qk__:"`
- Verify encoded value contains URI-encoded content (e.g., spaces become `%20`)

**decodeQuestionKey edge cases:**
- Non-prefixed key: `decodeQuestionKey("plain key")` returns `"plain key"` (passthrough)
- Malformed URI in prefixed key: `decodeQuestionKey("__qk__:%E0%A4%A")` returns `"__qk__:%E0%A4%A"` (raw key, catch path)

**encodeQuestionResponseMap / decodeQuestionResponseMap round-trip (AIPR-06):**

Test with a map containing mixed value types:
```typescript
const original = {
  "Is this an RCT?": true,
  "Adults only?": false,
  "Unclear methodology?": null,
};
const encoded = encodeQuestionResponseMap(original);
const decoded = decodeQuestionResponseMap(encoded);
expect(decoded).toEqual(original);
```

Verify encoded keys all start with `"__qk__:"` prefix.

Test with empty map:
```typescript
expect(decodeQuestionResponseMap(encodeQuestionResponseMap({}))).toEqual({});
```

Test with Unicode keys in map:
```typescript
const unicodeMap = { "这是什么？": true, "Ceci est-il vrai?": null };
expect(decodeQuestionResponseMap(encodeQuestionResponseMap(unicodeMap))).toEqual(unicodeMap);
```
