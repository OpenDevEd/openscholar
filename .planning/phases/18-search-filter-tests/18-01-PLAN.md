createSearchParameters logic (from lib/utils.ts lines 224-348):
- Maps searchField to `apiFilters[field] = { search: query }`
- Adds cites/cited_by/related_to with `https://openalex.org/` prefix if not already present
- Converts dateRange.from/to to `from_publication_date`/`to_publication_date` ISO strings
- Converts yearRange to `YYYY-01-01`/`YYYY-12-31` when no dateRange present
- Calls `getCountryCodesForRegions(filters.selectedRegions)` for country codes, sets `apiFilters.authorships.countries`
- Parses `sortBy` string as `field:order` for the sortBy object
- Sets `perPage: 200` and `AbstractArrayToString: true` always

### describe('createSearchParameters')

**1. Search field mapping using it.each** (SRCH-01 core):
```typescript
it.each([
  ['title_and_abstract', { title_and_abstract: { search: 'quantum' } }],
  ['title', { title: { search: 'quantum' } }],
  ['abstract', { abstract: { search: 'quantum' } }],
  ['fulltext', { fulltext: { search: 'quantum' } }],
  ['display_name', { display_name: { search: 'quantum' } }],
] as const)('maps field=%s to correct filter', (field, expected) => {
  const filters = { ...createDefaultFilters(), searchField: field };
  const result = createSearchParameters('quantum', filters);
  expect(result.filter).toMatchObject(expected);
});
```

**2. Empty query does not add search filter** -- Call with `''` and default filters. Assert `result.filter` is undefined (no filter keys).

**3. Cites filter with full URL** -- Set `citesItemId: 'https://openalex.org/W123'`. Assert `result.filter.cites === 'https://openalex.org/W123'` (no double prefix).

**4. Cites filter with bare ID** -- Set `citesItemId: 'W123'`. Assert `result.filter.cites === 'https://openalex.org/W123'` (prefix added).

**5. CitedBy filter** -- Set `citedByItemId: 'W456'`. Assert `result.filter.cited_by === 'https://openalex.org/W456'`.

**6. RelatedTo filter** -- Set `relatedToItemId: 'W789'`. Assert `result.filter.related_to === 'https://openalex.org/W789'`.

**7. Date range filter** -- Set `dateRange: { from: new Date('2024-01-15T00:00:00Z'), to: new Date('2024-06-30T00:00:00Z') }`. Assert `result.filter.from_publication_date === '2024-01-15'` and `result.filter.to_publication_date === '2024-06-30'`.

**8. Year range filter (no dateRange)** -- Set `yearRange: [2020, 2024]`, no dateRange. Assert `result.filter.from_publication_date === '2020-01-01'` and `result.filter.to_publication_date === '2024-12-31'`.

**9. Date range takes priority over year range** -- Set both `dateRange` and `yearRange`. Assert the date range values are used (not year range).

**10. Region/country filter** -- Set `selectedRegions: ['africa']` (which maps to many country codes via `getCountryCodesForRegions`). Assert `result.filter.authorships.countries` is a pipe-separated string of country codes.

**11. Sort by parsing** -- Set `sortBy: 'cited_by_count:desc'`. Assert `result.sortBy === { field: 'cited_by_count', order: 'desc' }`.

**12. Default sort** -- Set `sortBy: undefined` (or remove it). Assert `result.sortBy === { field: 'relevance_score', order: 'desc' }`.

**13. Base params always present** -- Any call. Assert `result.perPage === 200` and `result.AbstractArrayToString === true`.

**14. Multiple filters combined** -- Set `citesItemId`, `yearRange`, and a non-default `searchField` simultaneously. Assert all three are correctly present in `result.filter`.
