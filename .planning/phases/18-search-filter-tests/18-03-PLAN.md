buildFilterData logic:
- Returns FilterSection[] -- one section per active category
- Categories: search (field/sort), time (year/date), geographic (regions/countryFocus), content (review), ratings (range/onlyRated), citations (cites/citedBy/relatedTo)
- Only includes sections that have active (non-default) filters
- Uses DEFAULT_FILTERS from lib/utils.ts to check defaults
- Items contain LucideIcon components (don't deep-equal -- use toMatchObject on key/displayValue)

From lib/keyword-validation.ts:
```typescript
export function validateAndExpandKeywords(query: string, options?: ValidateAndExpandKeywordsOptions): KeywordValidationResult
export function validateAndExpandKeywordsSilently(query: string): KeywordValidationResult
export interface KeywordValidationResult {
  isValid: boolean;
  expandedQuery: string;
  warnings: string[];
}
```

Keyword expansion uses useKeywordExpansionStore.getState().expandQuery():
- Pattern: `(\w[\w-]*)\.\.\.` matches bookmarks like `ml...`
- If bookmark exists in store: replaces with expansion
- If not found: adds warning { key: 'bookmarkNotFound', params: { keyword } }
