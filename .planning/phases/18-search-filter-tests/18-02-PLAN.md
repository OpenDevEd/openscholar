Create `tests/region-codec.test.ts`. Import `encodeRegions`, `decodeRegions`, `INTERNAL_TO_URL_CODE`, `URL_CODE_TO_INTERNAL` from `../lib/search-params/regions`.

### describe('region codec bijectivity')

**1. Exhaustive encode-then-decode using it.each over all INTERNAL_TO_URL_CODE entries:**
```typescript
const allEntries = Object.entries(INTERNAL_TO_URL_CODE);

it.each(allEntries)(
  'encode([%s]) === %s and decode(%s) contains %s',
  (internal, urlCode) => {
    const encoded = encodeRegions([internal]);
    expect(encoded).toBe(urlCode);
    const decoded = decodeRegions(encoded);
    expect(decoded).toContain(internal);
  }
);
```
This verifies `decode(encode(x)) === x` for every entry.

**2. Exhaustive decode-then-encode for all URL_CODE_TO_INTERNAL entries:**
```typescript
const allReverse = Object.entries(URL_CODE_TO_INTERNAL);

it.each(allReverse)(
  'decode(%s) contains %s and encode(decode(%s)) === %s',
  (urlCode, internal) => {
    const decoded = decodeRegions(urlCode);
    expect(decoded).toContain(internal);
    const reEncoded = encodeRegions(decoded);
    expect(reEncoded).toBe(urlCode);
  }
);
```
This verifies `encode(decode(s)) === s` for every entry.

### describe('encodeRegions edge cases')

**3. Empty array** -- `encodeRegions([])` returns `''`

**4. Country code pass-through** -- `encodeRegions(['US'])` returns `'US'` (recognized 2-letter country code passes through)

**5. Multiple mixed items** -- `encodeRegions(['africa', 'US', 'europe'])` returns `'AF,US,EU'` (comma-separated, order preserved)

**6. Unknown item skipped** -- `encodeRegions(['nonexistent_region'])` returns `''` (unknown items silently skipped)

**7. Case insensitive for internal IDs** -- `encodeRegions(['AFRICA'])` returns `'AF'` (lowercased before lookup)

### describe('decodeRegions edge cases')

**8. Empty string** -- `decodeRegions('')` returns `[]`

**9. Whitespace-only** -- `decodeRegions('  ')` returns `[]`

**10. Country code pass-through** -- `decodeRegions('US')` returns `['US']`

**11. Multiple codes** -- `decodeRegions('AF,US,EU')` returns array containing `'africa'`, `'US'`, `'europe'`

**12. Unknown code ignored** -- `decodeRegions('XX_UNKNOWN')` returns `[]`

**13. Deduplication** -- `decodeRegions('AF,AF')` returns `['africa']` (only one entry due to Set dedup)

**14. Trimming whitespace around codes** -- `decodeRegions(' AF , EU ')` returns array containing `'africa'`, `'europe'`

**1. Empty array** -- `parseAsRegions.serialize([])` returns `''`. `parseAsRegions.parse('')` returns `[]`.

**2. Single region** -- `parseAsRegions.serialize(['africa'])` returns `'AF'`. `parseAsRegions.parse('AF')` returns array containing `'africa'`.

**3. Multiple regions and countries** -- `parseAsRegions.serialize(['africa', 'US', 'europe'])` produces string. Parsing that string back returns array containing all 3 items.

### describe('serializeSearchParams')

**4. Default params produce a query string** -- `serializeSearchParams(DEFAULT_SEARCH_PARAMS)` returns a non-empty string containing `q=` and `field=`.

**5. Custom query serializes correctly** -- Call with `{ ...DEFAULT_SEARCH_PARAMS, q: 'machine learning' }`. Assert result contains `q=machine+learning` or `q=machine%20learning`.

**6. Year filter serializes** -- Call with `{ ...DEFAULT_SEARCH_PARAMS, yf: 2020, yt: 2024 }`. Assert result contains `yf=2020` and `yt=2024`.

**7. Region filter serializes via parseAsRegions** -- Call with `{ ...DEFAULT_SEARCH_PARAMS, reg: ['africa', 'US'] }`. Assert result contains `reg=AF%2CUS` or `reg=AF,US` (URL-encoded comma).

**8. Boolean filter serializes** -- Call with `{ ...DEFAULT_SEARCH_PARAMS, review: true }`. Assert result contains `review=true`.
