Replace the entire content of `vitest.config.ts` with:
```typescript
import { defineConfig } from "vitest/config";
import react from "@vitejs/plugin-react";

export default defineConfig({
  plugins: [react()],
  test: {
    environment: "node",
    environmentMatchGlobs: [
      // Convex function tests need edge-runtime (convex-test requirement)
      ["convex/**/*.test.ts", "edge-runtime"],
      // React hook/component tests need jsdom for DOM APIs
      ["tests/hooks/**/*.test.ts", "jsdom"],
      ["tests/hooks/**/*.test.tsx", "jsdom"],
      ["tests/components/**/*.test.tsx", "jsdom"],
    ],
    server: {
      deps: {
        // Required for convex-test's dynamic module loading
        inline: ["convex-test"],
      },
    },
    include: ["tests/**/*.test.ts", "convex/**/*.test.ts"],
    exclude: ["tests/live-billing/**/*.test.ts"],
    setupFiles: ["./tests/setup.ts"],
  },
});
```

Key decisions in this config (do NOT deviate):
1. `environment: "node"` is the DEFAULT -- all 40 existing tests stay in node.
2. `environmentMatchGlobs` overrides for specific patterns only. First match wins.
3. `include` adds `convex/**/*.test.ts` alongside existing `tests/**/*.test.ts`.
4. `exclude` preserves `tests/live-billing/**/*.test.ts` (uses separate vitest.live.config.ts).
5. `plugins: [react()]` at root level -- required for JSX in future jsdom tests.
6. `setupFiles: ["./tests/setup.ts"]` points to the new global setup.
7. `server.deps.inline: ["convex-test"]` required per convex-test docs.
8. Do NOT add `globals: true` -- existing tests use explicit `import { describe, expect, it, vi } from "vitest"`.
