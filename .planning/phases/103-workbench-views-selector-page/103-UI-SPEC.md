## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`, `p-1`) | Icon gaps within badges, inline badge padding |
| sm | 8px (`gap-2`, `p-2`) | Badge clusters, compact row padding, evidence-quote internal padding |
| md | 16px (`gap-4`, `p-4`) | Default card padding, toolbar section gaps, tab content padding |
| lg | 24px (`gap-6`, `p-6`) | Section-level spacing between cards, result card internal sections |
| xl | 32px (`gap-8`, `p-8`) | Page outer padding, empty state centering |
| 2xl | 48px (`gap-12`) | Major vertical breaks (header to content) |
| 3xl | 64px (`gap-16`) | Not used in this phase |

Exceptions:
- Evidence drawer content padding: 20px (`px-5 py-4`) -- non-standard for comfortable reading width within the narrow Sheet
- Split view divider: 1px border (`border-r`) with no additional gap -- the panels use their own internal padding
- Touch targets on pagination Previous/Next: minimum 44px height (`h-11`) for mobile accessibility

## Interaction Specifications

### Evidence Drawer Open/Close

1. User clicks any `EvidenceQuote` element in any view (table cell, card, split detail)
2. The click handler calls `openEvidence({ paperId, startChar, endChar, questionText, parsingSource, modelUsed, criticVerdict })`
3. WorkbenchShell sets `drawerState.open = true` and passes props to EvidenceDrawer
4. Sheet opens from the right with default Radix animation
5. Close: click overlay, press Escape, or click Sheet close button
6. Evidence drawer is a single mount -- never per-row

### View Switching

1. User clicks a view option in ViewSwitcher (table/card/split)
2. `setActiveView(view)` updates Zustand store (persisted to localStorage)
3. AnimatePresence triggers exit animation on old view, enter on new view
4. Animation: `subtleSpring` (stiffness 350, damping 30, mass 0.8), opacity 0->1 + y 8->0
5. Reduced motion: `duration: 0` (instant swap, no animation)
6. If user selects split view on mobile (< 768px): auto-switch to table, fire toast

### Pagination Reset on Filter Change

1. User changes any column filter, global search text, or sort order
2. TanStack Table `autoResetPageIndex: true` resets `pageIndex` to 0
3. Pagination controls re-render showing "Showing 1--X of Y"
4. Card view virtualizer: `scrollToIndex(0)` when data changes

### Export Filtered Subset

1. User clicks Export dropdown in toolbar
2. If filters are active: dropdown shows "{count} filtered papers" note
3. User selects format (CSV / JSON / XLSX)
4. Handler reads `table.getFilteredRowModel().rows` to extract paper IDs
5. Calls `getExtractionResultsForExport` with optional `paperIds` filter
6. Generates file and triggers download
7. If no filters: exports all results (existing behavior)

### Selector Page Job Creation Flow

1. User adds papers across multiple tabs (library, collections, search, manual)
2. All additions go through `useAddToBasket` hook (cap-aware, deduplicating)
3. Counter updates in real time (sticky header + sticky footer)
4. User clicks "Start Extraction" CTA (disabled when basket empty)
5. ExtractionDialog opens with `papers` populated from basket store
6. User configures questions and tier in dialog (existing flow)
7. On successful `createExtractionJob`: basket clears, navigate to `/extraction/[newJobId]`

## Motion Contract

All animations use the existing `lib/animation-config.ts` presets. No new spring configs needed.

| Animation | Config | Trigger | Reduced Motion |
|-----------|--------|---------|----------------|
| View transition (table/card/split) | `subtleSpring` + `opacity: 0->1, y: 8->0` | View switcher click | `duration: 0` (instant) |
| Card entrance in card view | `cardEntrance` + `cardEntranceTransition(index * 0.05)` | Initial render of visible cards | Skipped entirely (raw content) |
| Evidence drawer open | Default Radix Sheet animation (slide from right) | Evidence quote click | Respects `prefers-reduced-motion` via Radix internals |
| Search clear button | None (instant show/hide) | Input non-empty / cleared | N/A |
| FilterSection active indicator | `motion.div` with `scaleY: 1` | Filter value set | `initial={false}` (no entrance animation) |

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Focus management | Evidence drawer traps focus on open (Radix Sheet built-in). Return focus on close. Tab content panels are focusable. |
| Keyboard navigation | Tabs: arrow keys to switch tabs (Radix Tabs built-in). Split view left panel: Up/Down arrow + Enter to select paper. Pagination: Tab to Previous/Next buttons. |
| Screen reader | Evidence drawer: `aria-label="Evidence detail for [question text]"`. Pagination: `aria-live="polite"` on "Showing X-Y of Z". Split view selected row: `aria-selected="true"`. Disabled Zotero tab: `aria-disabled="true"`. |
| Color contrast | All text meets WCAG AAA (7:1) against backgrounds. Badge text colors are OKLCH-tuned for both light and dark modes. |
| Touch targets | Pagination buttons: 44px min height. Tab triggers: 44px min height. Split view rows: 56px min height. |
| Reduced motion | All `motion/react` animations check `useReducedMotion()`. Sheet uses Radix's native reduced-motion support. Card entrance stagger skipped entirely. |
