<objective>
Replace the O(N) library count scan with a denormalized counter on the users table.

Purpose: The current `getLibraryCount` fetches up to 10,000 documents and returns `.length`. This is wasteful and breaks for users with >10,000 items. A denormalized counter makes reads O(1).

Output: Schema updated, all 3 mutation paths maintain the counter atomically, lazy backfill for existing users, full test coverage.
</objective>
