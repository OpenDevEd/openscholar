```typescript
"use client";
```

1. Import types and components:
   - `flexRender, type Table as TanStackTable` from `@tanstack/react-table`
   - `Table, TableBody, TableCell, TableHead, TableHeader, TableRow` from `@/components/ui/table`
   - `useTranslations` from `next-intl`
   - `cn` from `@/lib/utils`
   - `ArrowUp, ArrowDown, ArrowUpDown` from `lucide-react`

2. Define `WorkbenchDataTableProps<T>`:
   ```typescript
   interface WorkbenchDataTableProps<T> {
     table: TanStackTable<T>;
     className?: string;
   }
   ```

3. Implement `WorkbenchDataTable<T>({ table, className })`:

   **Header rendering:**
   - Map `table.getHeaderGroups()` into `TableRow` entries
   - Each header: if `header.isPlaceholder` render null, else render via `flexRender(header.column.columnDef.header, header.getContext())`
   - Sortable headers (`header.column.getCanSort()`): add `onClick={header.column.getToggleSortingHandler()}`, add `className="cursor-pointer select-none"`, render sort indicator icon:
     - sorted "asc": `<ArrowUp className="ml-1 inline h-3.5 w-3.5 text-primary" />`
     - sorted "desc": `<ArrowDown className="ml-1 inline h-3.5 w-3.5 text-primary" />`
     - unsorted: `<ArrowUpDown className="ml-1 inline h-3.5 w-3.5 text-muted-foreground opacity-0 group-hover:opacity-100 transition-opacity" />` (show on hover via parent `group` class)
   - Apply `font-semibold` override on `TableHead` (per UI-SPEC typography: two-weight system, headers use semibold not medium)
   - Sticky header: `className="sticky top-0 z-10 bg-card"` on `TableHeader`

   **Body rendering:**
   - Map `table.getRowModel().rows` into `TableRow` entries
   - Each row: `className="h-12"` (48px per UI-SPEC)
   - Each visible cell: `flexRender(cell.column.columnDef.cell, cell.getContext())`

   **Empty state:**
   - If `table.getRowModel().rows.length === 0`: render a single `TableRow` with a `TableCell` spanning all columns (`colSpan={table.getAllColumns().length}`), centered text using `t("extraction.workbench.noResults")` if table has column filters active, else `t("extraction.workbench.noData")`
   - Determine if filters active: `table.getState().columnFilters.length > 0`

4. Export `WorkbenchDataTable` as named export.

File-level JSDoc: `/** DataTable renderer bridging TanStack Table headless API to shadcn Table primitives via flexRender. Phase 101: WB-01. */`
