- On first server render: hook not called (client boundary). Server HTML has no `useIsMobile()` evaluation.

| Client viewport → UI render | Viewport size influences which UI elements render (view-switcher options, toolbar orientation). An adversary cannot spoof the viewport via HTTP; `window.innerWidth` is read client-side only. No trust-boundary crossing. |

| i18n locale JSON → UI render | Locale JSON files are shipped in the bundle; parsed at build-time via `getMessages()`. Not user-supplied at runtime. |
