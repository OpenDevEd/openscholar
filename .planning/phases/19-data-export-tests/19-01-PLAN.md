### describe('jsonToCSV')

**1. Empty array returns empty string:**
```typescript
expect(jsonToCSV([])).toBe('');
```

**2. Single object produces correct headers and values:**
```typescript
const csv = jsonToCSV([{ name: 'Alice', age: 30 }]);
const lines = csv.split('\n');
expect(lines[0]).toBe('age,name'); // sorted alphabetically
expect(lines[1]).toBe('30,Alice');
```

**3. Multiple objects with different keys -- headers are union of all keys, sorted:**
```typescript
const csv = jsonToCSV([
  { name: 'Alice', age: 30 },
  { name: 'Bob', city: 'NYC' }
]);
const lines = csv.split('\n');
expect(lines[0]).toBe('age,city,name'); // sorted union of keys
expect(lines[1]).toBe('30,,Alice');    // Bob's row has empty for age
expect(lines[2]).toBe(',NYC,Bob');     // Alice's row has empty for city
```

**4. Single object (non-array) is wrapped in array:**
```typescript
const csv = jsonToCSV({ name: 'Alice' });
const lines = csv.split('\n');
expect(lines).toHaveLength(2); // header + 1 data row
expect(lines[1]).toBe('Alice');
```

**5. Value with comma is escaped (quoted):**
```typescript
const csv = jsonToCSV([{ name: 'Smith, John' }]);
expect(csv).toContain('"Smith, John"');
```

**6. Value with double quotes is escaped (doubled and wrapped):**
```typescript
const csv = jsonToCSV([{ title: 'Say "hello"' }]);
expect(csv).toContain('"Say ""hello"""');
```

**7. Value with newline is escaped (quoted):**
```typescript
const csv = jsonToCSV([{ bio: 'Line 1\nLine 2' }]);
expect(csv).toContain('"Line 1\nLine 2"');
```

**8. Value with carriage return is escaped:**
```typescript
const csv = jsonToCSV([{ bio: 'Line 1\rLine 2' }]);
expect(csv).toContain('"Line 1\rLine 2"');
```

**9. Null and undefined values produce empty string:**
```typescript
const csv = jsonToCSV([{ a: null, b: undefined, c: 'ok' }]);
const lines = csv.split('\n');
// a and b should be empty
expect(lines[1]).toBe(',,ok'); // a='', b='', c='ok'
```

**10. Empty string value is quoted:**
```typescript
const csv = jsonToCSV([{ name: '' }]);
// escapeCSVValue('') returns '""'
expect(csv.split('\n')[1]).toBe('""');
```

**11. Object value is JSON-stringified:**
```typescript
const csv = jsonToCSV([{ data: { nested: true } }]);
// JSON.stringify({nested:true}) = '{"nested":true}' which contains quotes -> escaped
expect(csv).toContain('"{\\"nested\\":true}"');
// Actually: JSON.stringify produces {"nested":true}, then escapeCSVValue checks for special chars
// {"nested":true} contains " so it gets wrapped: "{""nested"":true}"
```
Wait -- let me trace the actual logic. `escapeCSVValue({nested: true})` -> `JSON.stringify({nested: true})` -> `'{"nested":true}'` -> contains `"` -> `'"' + '{"nested":true}'.replace(/"/g, '""') + '"'` -> `'"{""nested"":true}"'`. So:
```typescript
const csv = jsonToCSV([{ data: { nested: true } }]);
expect(csv.split('\n')[1]).toBe('"{""nested"":true}"');
```

**12. Number value is not quoted:**
```typescript
const csv = jsonToCSV([{ count: 42 }]);
expect(csv.split('\n')[1]).toBe('42');
```

**13. Boolean value is not quoted:**
```typescript
const csv = jsonToCSV([{ active: true }]);
expect(csv.split('\n')[1]).toBe('true');
```

**14. Header names with special characters are escaped:**
```typescript
const csv = jsonToCSV([{ 'Question, Answer': 'yes' }]);
expect(csv.split('\n')[0]).toContain('"Question, Answer"');
```
