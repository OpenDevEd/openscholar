- `"use client"` directive
- State: `searchText` (string), `sortBy` (savedAt|rating|publicationYear, default "savedAt"), `sortOrder` (asc|desc, default "desc"), `minRating` (number|undefined), `expandedItemId` (string|null)

- **Dual-path query orchestrator (LIB-11):**
  - `searchResults = useProtectedPaginatedQuery(api.library.queries.searchLibrary, hasSearchText ? { searchText: debouncedSearch, minRating } : "skip", { initialNumItems: 20 })`
  - `browseResults = useProtectedPaginatedQuery(api.library.queries.browseLibrary, !hasSearchText ? { sortBy, sortOrder, minRating } : "skip", { initialNumItems: 20 })`
  - `activeResults = hasSearchText ? searchResults : browseResults`
- Use `useProtectedQuery(api.library.queries.getLibraryCount, {})` for total count
- Removal: `const removeItem = useMutation(api.library.mutations.removeFromLibrary)`, wrapped in `showConfirmation()` with title "Remove from library", message "Remove \"{title}\" from your library?", confirmText "Remove", variant "destructive"
- Layout (top to bottom):
  1. Header: "Your Library" heading + total count badge (e.g., "42 papers")
  2. `<LibrarySearchBar>` -- full width
  3. `<LibraryFilters>` -- rating filter + sort dropdown
  4. Item list: map `activeResults.results` to `<LibraryItemRow>` components
  5. Loading: show `<LibraryItemSkeleton>` (5 rows) when `activeResults.isInitialLoading`
  6. Empty states: `<LibraryEmptyState>` when results empty
  7. Load more: button at bottom when `activeResults.status === "CanLoadMore"`, calls `activeResults.loadMore(20)`
- When `hasSearchText` is true, disable the sort dropdown (search mode is relevance-ordered, sort does not apply)
- Pass `onRemove`, `expandedItemId`, `onToggleExpand` as props to item rows

- Full-width `<Input>` with search icon (lucide `Search`)

- Placeholder: translated "Search by title, author, or abstract..."
- Clear button (X icon) when text is non-empty

**4. `components/library/library-filters.tsx`**:
- **Rating star filter:** Row of 5 clickable stars. Click star N to set minRating=N (show N and above). Click same star again to clear filter (set minRating=undefined). Active stars are filled, inactive are outlined. Use lucide `Star` icon.
- **Sort dropdown:** `<Select>` component with options: "Date saved", "Rating", "Publication year". Each shows current sort direction. Adjacent toggle button (lucide `ArrowUpDown` or `ArrowUp`/`ArrowDown`) to flip asc/desc. Disabled when search mode is active (prop `sortDisabled`).
- Props: `minRating`, `onMinRatingChange`, `sortBy`, `onSortByChange`, `sortOrder`, `onSortOrderChange`, `sortDisabled`

**5. `components/library/library-item-row.tsx`**:
- Compact single-line row per user decision: rating stars (small, display-only), title (truncated), authors (truncated), publication year, journal name, cited_by_count, open access badge
- Open access badge: small colored pill based on `oaStatus` (gold/green/bronze/hybrid) or hidden if closed/undefined
- Click row to expand/collapse (controlled by parent via `isExpanded` / `onToggleExpand` props)
- Expanded section: abstract text + link to full paper via DOI (opens in new tab). Use `AnimatePresence` + `motion.div` from `motion/react` for expand/collapse animation with height: 0 -> "auto"
- Three-dot overflow menu: `<DropdownMenu>` with `<DropdownMenuTrigger>` using `MoreHorizontal` icon. Single menu item: "Remove from library". `onClick` calls `onRemove(item)`. Use `e.stopPropagation()` on trigger to prevent row expand.
- Keyboard accessible: `role="button"`, `tabIndex={0}`, `onKeyDown` for Enter/Space
- Hover state: subtle background highlight

**6. `components/library/library-item-skeleton.tsx`**:
- Skeleton row matching compact layout dimensions
- Uses shadcn `Skeleton` component for animated placeholder bars
- Accepts `count` prop (default 5) to render multiple skeleton rows

**7. `components/library/library-empty-state.tsx`**:
- Two modes via `variant` prop: "empty-library" and "no-results"
- **empty-library:** Icon (lucide `BookMarked` or `Library`), heading "Your library is empty", description text, CTA `<Link>` button to "/" (home/search page)
- **no-results:** Inline message "No papers match your search/filters", "Clear filters" button that calls `onClearFilters` prop
- All strings use `useTranslations("libraryPage")` for i18n

Use existing design patterns from the codebase: Tailwind classes, shadcn components, motion/react for animations. List rows should feel compact and scannable -- more like Linear's issue list than a cluttered academic table.
