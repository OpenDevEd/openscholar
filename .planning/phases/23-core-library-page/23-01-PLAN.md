**Create `convex/library/queries.ts`** with three exported query functions:

1. **`browseLibrary`** -- paginated browse with custom sort:
   - Args: `sortBy` (literal union: "savedAt" | "rating" | "publicationYear"), `sortOrder` (literal union: "asc" | "desc"), `minRating` (optional number), `paginationOpts` (paginationOptsValidator)
   - Handler: `requireAuth(ctx)`, then query `libraryItems` using index map: savedAt -> "by_user_savedAt", rating -> "by_user_rating", publicationYear -> "by_user_year". Apply `.withIndex(indexMap[sortBy], q => q.eq("userId", user._id)).order(sortOrder)`. If `minRating` is provided, wrap with `filter()` from `convex-helpers/server/filter` using predicate `item => item.rating >= minRating`. Then `.paginate(paginationOpts)`.
   - Returns: paginated result

2. **`searchLibrary`** -- text search with relevance ordering:
   - Args: `searchText` (string), `minRating` (optional number), `paginationOpts` (paginationOptsValidator)
   - Handler: `requireAuth(ctx)`, then query `libraryItems.withSearchIndex("search_library", q => q.search("searchableText", searchText).eq("userId", user._id))`. If `minRating` is provided, wrap with `filter()` from `convex-helpers/server/filter` using predicate `item => item.rating >= minRating`. Then `.paginate(paginationOpts)`.
   - Returns: paginated result
   - CRITICAL: Do NOT chain `.order()` on search queries -- Convex search always returns relevance order. Adding `.order()` would be silently ignored (see RESEARCH.md Pitfall 1).

3. **`getLibraryCount`** -- total item count:
   - Args: none
   - Handler: `requireAuth(ctx)`, query `libraryItems.withIndex("by_user", q => q.eq("userId", user._id)).collect()`, return `items.length`.
   - Note: Works for libraries up to 1024 items (Convex .collect() limit). Acceptable for MVP.
   - Returns: number
