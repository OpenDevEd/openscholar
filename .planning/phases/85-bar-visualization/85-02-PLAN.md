<feature>
  <name>StackedAnswerBars component (TDD)</name>
  <files>components/extraction/stacked-answer-bars.tsx, tests/stacked-answer-bars.test.tsx</files>
  <behavior>
    Component props interface (StackedAnswerBarsProps):
    - answers: Array<{ answer: string; count: number; citationStatusMix: { grounded: number; best_effort: number; insufficient_evidence: number; extraction_error: number } }>
    - maxCount: number  — the max across ALL answers in the question (for consistent X axis domain)

    Rendering behavior:
    - One bar row per answer item
    - Each row shows: answer label (truncated), count number, stacked Recharts BarChart (layout="vertical")
    - Bar chart uses XAxis type="number" with domain [0, safMax] (Math.max(maxCount, 1)) and YAxis type="category" both hidden
    - Four stacked Bar components each with stackId="status", fill from CITATION_STATUS_COLORS
    - Segments with count=0 still present in data but render as zero-width (Recharts handles gracefully)
    - Empty state: if answer.count === 0 for all items, render a muted "No answers" message instead of chart
    - Each row wrapped in a div with data-testid="answer-bar-row"

    BAR-03 guards in rendering:
    - safMax = Math.max(maxCount, 1) — prevents XAxis domain of [0, 0]
    - Zero-count answers display label + "0" count but no broken chart (empty state path)

    Mock Recharts in tests using vi.mock("recharts") to avoid jsdom canvas/SVG issues. The mock should render a div with data-testid="recharts-mock" containing the data props as JSON for assertion. This is the same pattern used in Phase 84 for Radix Tooltip.
  </behavior>
  <implementation>
    After tests pass: implement StackedAnswerBars using Recharts BarChart + Bar + ResponsiveContainer.
    Import CITATION_STATUS_COLORS from lib/extraction/bar-scaling.ts.
    No i18n needed for this component (count numbers and answer strings are data, not UI strings).
    "use client" directive required (Recharts is browser-only).
  </implementation>
</feature>
