**Step 3: Create the implementation** at `lib/library/trim-paper-data.ts`:

```typescript
import type { TrimmedPaperData } from "@/lib/types/library.types";

/**
 * Extracts the 10 required metadata fields from an OpenAlex Work object.
 * Called client-side before sending to the Convex saveToLibrary mutation
 * to avoid sending the full 5-20 KB Work blob over the wire.
 */
export function trimPaperData(work: Record<string, any>): TrimmedPaperData {
  const authors = work.authorships
    ?.map((a: any) => a.author?.display_name)
    .filter(Boolean)
    .join(", ") || undefined;

  return {
    openalexId: work.id,
    title: work.title || work.display_name || "",
    authors,
    doi: work.doi || undefined,
    abstract: work.abstract || undefined,
    publicationYear: work.publication_year || undefined,
    journal: work.primary_location?.source?.display_name || undefined,
    citedByCount: work.cited_by_count ?? undefined,
    isOpenAccess: work.open_access?.is_oa ?? undefined,
    oaStatus: work.open_access?.oa_status || undefined,
  };
}
```

Note the deliberate use of `||` for strings (converts empty string to undefined) and `??` for booleans/numbers (preserves `false` and `0`).

**Step 2: Create `convex/library/mutations.ts`** with the `saveToLibrary` upsert mutation:

```typescript
import { mutation } from "../_generated/server";
import { v } from "convex/values";
import { requireAuth } from "../lib/auth";

export const saveToLibrary = mutation({
  args: {
    openalexId: v.string(),
    rating: v.number(),
    title: v.string(),
    authors: v.optional(v.string()),
    doi: v.optional(v.string()),
    abstract: v.optional(v.string()),
    publicationYear: v.optional(v.number()),
    journal: v.optional(v.string()),
    citedByCount: v.optional(v.number()),
    isOpenAccess: v.optional(v.boolean()),
    oaStatus: v.optional(v.string()),
  },
  returns: v.id("libraryItems"),
  handler: async (ctx, args) => {
    const user = await requireAuth(ctx);

    const searchableText = [args.title, args.abstract, args.authors]
      .filter(Boolean)
      .join(" ");

    // Upsert: check if paper already in user's library
    const existing = await ctx.db
      .query("libraryItems")
      .withIndex("by_user_openalexId", (q) =>
        q.eq("userId", user._id).eq("openalexId", args.openalexId)
      )
      .unique();

    if (existing) {
      // Re-rate: only update rating and timestamps, preserve original metadata and savedAt
      await ctx.db.patch(existing._id, {
        rating: args.rating,
        searchableText,
        updatedAt: Date.now(),
      });
      return existing._id;
    }

    // New save: insert full document
    return await ctx.db.insert("libraryItems", {
      userId: user._id,
      ...args,
      searchableText,
      savedAt: Date.now(),
      updatedAt: Date.now(),
    });
  },
});
```

Key decisions:
- Mutation receives already-trimmed fields (client calls `trimPaperData` before invoking). No `v.any()` blob.
- On re-rate, only `rating`, `searchableText`, and `updatedAt` are patched. Metadata fields are NOT updated (same OpenAlex source, don't change). `savedAt` is preserved as original save time.
- `searchableText` is concatenation of title + abstract + authors for Phase 23 search index.
- Auth via `requireAuth(ctx)` -- throws UNAUTHENTICATED for anonymous callers.

**Important:** Do NOT create `convex/library/queries.ts` yet. That is Phase 23 scope. Only create the mutations file.
