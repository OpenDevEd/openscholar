Modify `getJobInsights` handler (line 678-794) to attempt a fast-path read from `extractionJobStats` for the per-question scalar counters. The fast path supplements the existing fan-out by avoiding redundant recomputation when stats exist, but it does NOT fully replace the fan-out because `topAnswers`, `entityDistribution`, `reviewed`, `noContentPapers`, and `abstractOnlyCount` require individual paper/result data.

**Strategy:** Since the per-question `questions` array in the return type requires `topAnswers`, `entityDistribution`, and `reviewed` (which stats cannot provide), the full fan-out is still needed for the `questions` array. The optimization is: use stats for the **summary** section only, bypassing the aggregation loops for summary counters.

However, re-reading the requirements and research more carefully: `getJobInsights` must still load papers for `noContentPapers` (diagnostics), `abstractOnlyCount`, and the per-question detail arrays. The summary counters (answeredTotal, groundedTotal, rates, avgConfidence) are the ONLY fields derivable from stats. Since the fan-out is still required for per-question details, the win here is marginal for `getJobInsights` specifically.

**Revised approach per research "Pattern 4: Stats Scope and Limitations":**
The primary win is for the `getJobInsights` **summary section** scalars AND for `createExtractionReportSnapshot` **metrics** (Task 2). For `getJobInsights`, the fan-out remains for per-question detail, but we add a stats check that can SHORT-CIRCUIT the summary aggregation (skip the secondary `answeredTotal += aggregate.answered` loops) when stats exist. The net code change is small but establishes the pattern.

**A. Backfill mutation (new function):**

Add a `backfillJobStats` internal mutation that computes stats from existing results and persists them. This enables legacy completed jobs to get stats on first mutation-context access.

```typescript
export const backfillJobStats = internalMutation({
  args: { jobId: v.id("extractionJobs") },
  returns: v.null(),
  handler: async (ctx, args): Promise<null> => {
    // Check if stats already exist (idempotent)
    const existingStats = await ctx.db
      .query("extractionJobStats")
      .withIndex("by_job", (q) => q.eq("jobId", args.jobId))
      .first();
    if (existingStats) return null; // Already backfilled

    const questions = await ctx.db
      .query("extractionQuestions")
      .withIndex("by_job", (q) => q.eq("jobId", args.jobId))
      .order("asc")
      .collect();

    const papers = await ctx.db
      .query("extractionPapers")
      .withIndex("by_job", (q) => q.eq("jobId", args.jobId))
      .take(MAX_PAPERS_PER_JOB);

    for (const question of questions) {
      let totalPapers = 0;
      let totalAnswered = 0;
      let groundedCount = 0;
      let bestEffortCount = 0;
      let insufficientEvidenceCount = 0;
      let extractionErrorCount = 0;
      let confidenceSum = 0;
      let confidenceCount = 0;
      let highConfidenceCount = 0;
      let mediumConfidenceCount = 0;
      let lowConfidenceCount = 0;
      let unknownConfidenceCount = 0;

      for (const paper of papers) {
        if (paper.processable === false) continue;
        const results = await ctx.db
          .query("extractionResults")
          .withIndex("by_paper", (q) => q.eq("paperId", paper._id))
          .collect();
        const result = results.find(r => r.questionKey === question.key);
        if (!result) {
          totalPapers += 1;
          unknownConfidenceCount += 1;
          continue;
        }

        totalPapers += 1;
        const isAnswered = result.answer !== null && result.answer !== undefined;
        totalAnswered += isAnswered ? 1 : 0;
        groundedCount += result.citationStatus === "grounded" ? 1 : 0;
        bestEffortCount += result.citationStatus === "best_effort" ? 1 : 0;
        insufficientEvidenceCount += result.citationStatus === "insufficient_evidence" ? 1 : 0;
        extractionErrorCount += result.citationStatus === "extraction_error" ? 1 : 0;

        const conf = typeof result.confidence === "number" ? result.confidence : undefined;
        if (conf !== undefined) {
          confidenceSum += conf;
          confidenceCount += 1;
          if (conf >= 0.8) highConfidenceCount += 1;
          else if (conf >= 0.5) mediumConfidenceCount += 1;
          else lowConfidenceCount += 1;
        } else {
          unknownConfidenceCount += 1;
        }
      }

      await ctx.db.insert("extractionJobStats", {
        jobId: args.jobId,
        questionKey: question.key,
        totalPapers,
        totalAnswered,
        groundedCount,
        bestEffortCount,
        insufficientEvidenceCount,
        extractionErrorCount,
        confidenceSum,
        confidenceCount,
        highConfidenceCount,
        mediumConfidenceCount,
        lowConfidenceCount,
        unknownConfidenceCount,
        updatedAt: Date.now(),
      });
    }

    return null;
  },
});
```

Register it in the internal API -- since it's an `internalMutation` export in `convex/extraction/mutations.ts`, it automatically registers as `internal.extraction.mutations.backfillJobStats`.
