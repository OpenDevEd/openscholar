<objective>
Add deterministic citation grounding to the extraction cascade: Levenshtein verification via Zod superRefine, same-model critic pass, insufficient_evidence first-class answer state, and persistence wiring.

Purpose: Prevent hallucinated evidence quotes from reaching users. Every extraction answer must have its evidence quote verified against the actual source text at >=85% Levenshtein similarity, then confirmed by a critic pass. Answers that fail either check become `insufficient_evidence` -- a valid extraction outcome with capped confidence.

Output: Modified `extract.ts` with superRefine + critic, `buildCriticPrompt` in prompts.ts, `criticVerdict` persistence in mutations/workpoolActions, `getPaperBodyText` query, and comprehensive unit tests.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM output -> extraction pipeline | Untrusted: LLM may hallucinate evidence quotes that do not exist in the source text |
| Client -> getPaperBodyText query | Untrusted: client may request another user's paper bodyText |
| Critic LLM output -> verdict handling | Semi-trusted: critic is an LLM and can itself hallucinate, but Output.object enforces schema |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-92-01 | Information Disclosure | getPaperBodyText query | mitigate | User isolation check: load paper -> load job -> verify job.userId === user._id before returning bodyText |
| T-92-02 | Spoofing | LLM evidence_quote | mitigate | Levenshtein superRefine rejects quotes with <85% similarity to actual source text; UI renders bodyText.slice() not LLM output |
| T-92-03 | Tampering | Critic verdict | mitigate | Critic output validated via Output.object({ schema: criticOutputSchema }) with z.enum -- only "supported", "unsupported", "partial" accepted |
| T-92-04 | Denial of Service | Critic pass timeout | mitigate | AbortSignal.timeout(30_000) on critic call; timeout does not reject the answer (lenient policy) |
| T-92-05 | Elevation of Privilege | extractionResults criticVerdict field | accept | Field is v.optional(v.string()); no privilege implications -- purely informational for audit trail |
</threat_model>
