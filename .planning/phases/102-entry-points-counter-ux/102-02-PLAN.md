**Component logic:**

1. Call `useAddToBasket()` to get `addToBasket`, `removeFromBasket`, `limit`.

3. Compute `inBasket` using the normalized ID: `const normalizedId = useMemo(() => normalizeOpenAlexId(paper.rawId), [paper.rawId]);` then `const inBasket = normalizedId ? useExtractionBasketStore((s) => s.has(normalizedId)) : false;` -- BUT since `has()` is not a reactive selector (it reads from `get()` not `set()`), instead use `useExtractionBasketStore((s) => normalizedId ? s.papers.has(normalizedId) : false)` for reactive updates.
4. Compute `isAtCap`: `const isAtCap = count >= limit;` per D-13.
5. Use `useTranslations("extraction.addButton")` for tooltip text.
6. Button is `disabled` when `isAtCap && !inBasket` (papers already in basket remain toggleable for removal).

**Click handler:**
```typescript
const handleToggle = useCallback(() => {
  if (inBasket) {
    removeFromBasket(paper.rawId);
  } else {
    const result = addToBasket({
      rawId: paper.rawId,
      title: paper.title,
      doi: paper.doi,
      source,
    });
    if (result.dropped > 0) {
      toast.info(t("dropped", { added: result.added, dropped: result.dropped }));
    }
  }
}, [inBasket, addToBasket, removeFromBasket, paper, source, t]);
```

**Tooltip text logic** (per D-06):
- `isAtCap && !inBasket` -> `t("basketFull")`
- `inBasket` -> `t("inBasket")`
- default -> `t("add")`

      aria-label={inBasket ? t("inBasket") : t("add")}
