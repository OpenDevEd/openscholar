## Objective

Add "title" as a fourth sort option for library items (DISP-01), and extend the URL search params with a page number for pagination (DISP-03 data layer). This plan handles all backend and data-layer changes; the UI integration is in 34-02.

DISP-02 (sort disabled during search) is already implemented -- this plan verifies it works correctly as part of the sort option extension.

## Context

@convex/schema.ts -- libraryItems table definition, lines 633-658. Current indexes: by_user, by_user_openalexId, by_user_rating, by_user_savedAt, by_user_year. Needs new `by_user_title` index.

@convex/library/queries.ts -- browseLibrary and exportLibrary queries. Both have `indexMap` and `sortBy` validators that need "title" added.

@lib/library/search-params.ts -- nuqs parsers for library URL state. `librarySortValues` needs "title", and a new `p` param for page number.

@messages/en-US.json -- libraryPage namespace. Needs `sortTitle`, `showingRange`, `previousPage`, `nextPage` i18n keys.
