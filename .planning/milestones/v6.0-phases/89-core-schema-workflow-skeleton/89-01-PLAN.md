NOTE on D-05 discretion: Use a separate `extractionQuestions` table rather than nested array on the job. Per Convex AI guidelines: "Do not store unbounded lists as an array field inside a document." While extraction questions are bounded (~3-10), a separate table keeps each question independently queryable for Phase 91 per-question parallelism. The `questions` field on `extractionJobs` still exists as a denormalized snapshot for progress UI (matching screening pattern), but the canonical questions live in the separate table.
