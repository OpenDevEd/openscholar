- Message matches `"404"` or `"not found"` (case-insensitive) -> `{ retryable: false, category: "not_found" }`
- Message matches `"400"` or `"bad request"` (case-insensitive) -> `{ retryable: false, category: "bad_request" }`
- Message matches `"ZodError"` or `"validation"` -> `{ retryable: false, category: "validation" }`
- Message matches `"empty body"` or `"no body text"` -> `{ retryable: false, category: "empty_body" }`
- Message matches `"page"` AND `"exceeded"` (both present) -> `{ retryable: false, category: "page_limit" }`
- Default fallback -> `{ retryable: true, category: "network" }` (safe default: workpool maxAttempts: 3 caps wasted retries)

The `message` field is extracted via `error instanceof Error ? error.message : String(error)`.
