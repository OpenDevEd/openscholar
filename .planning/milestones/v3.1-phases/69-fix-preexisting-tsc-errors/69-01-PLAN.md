**convex/extraction/index.ts** -- Remove all re-exports of `"use node"` files. These files are already individually registered by the Convex bundler; re-exporting them from a non-"use node" barrel file causes the bundler to fail when it encounters transitive `node:crypto` imports.

Remove these lines:
- Line 14: `export { fetchPapersFromHistory } from "./actions";`
- Lines 17-20: `export { downloadAndIndexPdfAction, waitAndExtractAction } from "./workpoolActions";`
- Line 97: `export { debugPdfAlignment } from "./debug_pdfjs_alignment";`
- Line 109: `export { runPdfTestNow } from "./test_automation";`

Add a comment block where the exports were removed explaining WHY:
```typescript
// Note: "use node" action files (actions.ts, workpoolActions.ts,
// debug_pdfjs_alignment.ts, test_automation.ts) are NOT re-exported here.
// Re-exporting from a non-"use node" barrel file causes the Convex bundler
// to fail on transitive node:crypto imports. These files are registered
// individually by the Convex bundler via their own module entries.
```

Keep ALL other re-exports unchanged. The remaining files are either non-"use node" modules or type-only exports.

**convex/crons.ts** -- Add empty `{}` as 4th argument to the `checkSubscriptionStatus` interval call (line 14). The function has optional args (`startIndex`, `startedAt`) which still requires the 4th parameter in the TS type signature.

Change:
```typescript
crons.interval(
  "check subscription status",
  { hours: 1 },
  internal.maintenance.internal.checkSubscriptionStatus
);
```
To:
```typescript
crons.interval(
  "check subscription status",
  { hours: 1 },
  internal.maintenance.internal.checkSubscriptionStatus,
  {},
);
```
