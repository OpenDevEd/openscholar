<objective>
Move pending plan change state (fromPlan, toPlan, timestamp) from Stripe subscription metadata to the Convex `subscriptions` table, making Convex the source of truth for pending plan changes.

Purpose: Stripe metadata is unreliable for state management -- it can be overwritten by other Stripe operations, is not transactional, and requires an API call to read. Storing in Convex provides atomic reads/writes, consistency, and eliminates a Stripe API round-trip when checking pending state (BILL-02).
Output: Schema migration adding pending plan change fields, updated actions writing/reading from Convex, and backward-compatible Stripe metadata writes for the invoice webhook path.
</objective>
