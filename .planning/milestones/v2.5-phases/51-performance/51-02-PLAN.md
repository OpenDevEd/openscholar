  **Step 2: Refactor `cleanupExpiredOAuthTokens` in `convex/zotero/mutations.ts` (lines 153-179).**

  Replace the full table scan with an index-based query that only reads expired tokens:

  ```typescript
  export const cleanupExpiredOAuthTokens = internalMutation({
    args: {},
    returns: v.null(),
    handler: async (ctx) => {
      const now = Date.now();
      // Use by_expiry index: only fetch tokens that have already expired
      const expiredTokens = await ctx.db
        .query("zoteroOAuthTokens")
        .withIndex("by_expiry", (q) => q.lt("expiresAt", now))
        .take(100);

      let deletedCount = 0;
      for (const token of expiredTokens) {
        try {
          await ctx.db.delete(token._id);
          deletedCount++;
        } catch {
          // Token may have been deleted by getRequestToken or concurrent process.
          // Safe to ignore -- Convex OCC retries handle this gracefully.
        }
      }

      if (deletedCount > 0) {
        console.log(`[cleanupExpiredOAuthTokens] Deleted ${deletedCount} expired token(s)`);
      }

      return null;
    },
  });
  ```

  Key changes:
  - `.query("zoteroOAuthTokens").collect()` (full scan) becomes `.withIndex("by_expiry", q => q.lt("expiresAt", now)).take(100)` (index scan + bounded)
  - The `.take(100)` bounds memory usage per cron run
  - The JS-side `if (token.expiresAt < now)` filter is eliminated because the index handles it
