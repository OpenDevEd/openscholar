Replace all 4 instances of `continueCursor: "" as any` in `convex/library/queries.ts` with a properly typed empty cursor.

1. Add `Cursor` to the existing import from `convex/server`:
   - Change: `import { paginationOptsValidator } from "convex/server";`
   - To: `import { paginationOptsValidator, type Cursor } from "convex/server";`

   Note: `Cursor` is exported from `convex/server` as `type Cursor = string`. Importing it as a type import ensures it's erased at runtime.

2. Replace all 4 occurrences (lines 32, 45, 106, 119):
   - From: `return { page: [], isDone: true, continueCursor: "" as any };`
   - To: `return { page: [], isDone: true, continueCursor: "" as Cursor };`

This is a safe change because `Cursor` is literally `string`, so `"" as Cursor` is a valid widening cast. The key improvement is that if Convex changes `Cursor` to a branded type in the future, TypeScript will flag these sites for update rather than silently allowing any value through `as any`.

Run `npx convex typecheck` (not just tsc) to verify Convex-specific validation passes.
