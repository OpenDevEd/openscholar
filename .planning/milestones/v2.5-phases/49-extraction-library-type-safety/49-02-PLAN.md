```typescript
  query: v.optional(v.string()),

  relatedToItemId: v.optional(v.string()),
  isYearRangeEnabled: v.optional(v.boolean()),
  filterType: v.optional(v.string()),
  ratingRange: v.optional(v.array(v.number())),
  onlyRatedPapers: v.optional(v.boolean()),
  language: v.optional(v.string()),
  perPage: v.optional(v.number()),
  limit: v.optional(v.number()),
});
```

**CRITICAL**: Every field MUST be `v.optional()`. This validator is applied to existing stored data, so if any field was absent in previously-stored records, a required field would cause runtime validation failures. The `perPage` and `limit` fields are included because test jobs (create_test_job.ts, testWorkflow.ts) add them to searchFilters.
