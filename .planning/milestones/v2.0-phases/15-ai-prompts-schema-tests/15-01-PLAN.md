Create `tests/ai-validate.test.ts` with tests for `validateQuery`, `repairJSON`, and `repairSingleField`.

Import from `../lib/ai/core/validate`. Use `import { describe, expect, it } from "vitest"`.

**validateQuery tests (AIPR-02):**

Valid queries (should return the query string without throwing):
- `"(AI OR ML) AND health"` -- balanced parens
- `"climate change"` -- no parens at all
- `"((nested)) AND test"` -- deeply nested parens
- `""` -- empty string (no parens, no trailing operator)

Invalid queries (should throw):
- `"(AI OR ML AND health"` -- unbalanced: more opens than closes. Use `expect(() => validateQuery(...)).toThrow("unbalanced parentheses")`
- `"AI AND health)"` -- unbalanced: more closes than opens
- `"AI OR"` -- trailing OR
- `"health AND "` -- trailing AND (note: trailing whitespace after AND still matches regex `AND\s*$`)
- `"NOT"` -- trailing NOT (entire string is "NOT")

**repairJSON tests (AIPR-03):**

IMPORTANT: `repairJSON` and `repairSingleField` are async -- always `await` them.

Path 1 -- Non-JSON text (does not start with `{`):
- `await repairJSON("  hello world  ", null)` returns `"hello world"` (trimmed)
- `await repairJSON("plain text answer", null)` returns `"plain text answer"`

Path 2 -- Repairable JSON:
- `await repairJSON('{"key": "value",}', null)` -- result is valid JSON (parse it with `JSON.parse` to verify, should have `key: "value"`)
- `await repairJSON("{key: 'value'}", null)` -- result is valid JSON with `key: "value"` (unquoted keys, single quotes fixed)

Path 3 -- Unrepairable JSON-like text:
- `await repairJSON("{completely broken {{{{", null)` returns `null`

Edge case -- Non-JSON text that falls to catch block:
- Verify the catch block path: text that starts with `{` but fails `jsonrepair` AND also starts with `{` (so the catch branch's `if` fails) returns `null`. Example: `"{{{{{{{{{{"` (all braces, unrepairable)

**repairSingleField tests (AIPR-03):**

- Non-JSON text wrapping: `await repairSingleField("hello world", null, "enhancedQuery")` -- result parses to `{ enhancedQuery: "hello world" }`
- JSON passthrough: `await repairSingleField('{"enhancedQuery": "test",}', null, "enhancedQuery")` -- result parses to `{ enhancedQuery: "test" }`
- Null propagation: `await repairSingleField("{{{broken", null, "field")` -- returns `null` (when repairJSON returns null)
