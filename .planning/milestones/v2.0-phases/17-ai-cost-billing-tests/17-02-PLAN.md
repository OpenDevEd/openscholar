1. **Returns zero pricing for unknown model** -- Call `getModelPricing('openai', 'nonexistent-model')`. Assert `toEqual({ input: 0, output: 0 })`.

3. **Parametric known-model pricing using it.each** -- Test one representative model per provider:
   ```typescript
   const pricingCases = [
     { provider: 'openai' as AIProvider, modelId: 'gpt-5-nano', expected: { input: 0.05, output: 0.40 } },
     { provider: 'anthropic' as AIProvider, modelId: 'claude-3-haiku', expected: { input: 0.25, output: 1.25 } },
     { provider: 'google' as AIProvider, modelId: 'gemini-2.5-flash-lite', expected: { input: 0.10, output: 0.40 } },
     { provider: 'deepseek' as AIProvider, modelId: 'deepseek-coder', expected: { input: 0.14, output: 0.28 } },
   ]
   ```
   For each case, call `getModelPricing(provider, modelId)` and assert `toEqual(expected)`.

4. **Returns zero pricing for azure (empty model list)** -- Call `getModelPricing('azure' as AIProvider, 'gpt-5-mini')`. Assert `toEqual({ input: 0, output: 0 })`.

### describe('getModelById') (AICB-04)

1. **Returns model config for known model** -- Call `getModelById('openai', 'gpt-5-nano')`. Assert result is defined with correct fields: `id: 'gpt-5-nano'`, `name: 'GPT-5 Nano'`, `provider: 'openai'`, `pricing: { input: 0.05, output: 0.40 }`.

2. **Returns undefined for unknown model** -- Call `getModelById('openai', 'nonexistent-model')`. Assert result `toBeUndefined()`.

3. **Returns undefined for openrouter** -- Call `getModelById('openrouter' as AIProvider, 'any-model')`. Assert result `toBeUndefined()`.

4. **Returns model from each provider using it.each**:
   ```typescript
   const modelCases = [
     { provider: 'openai' as AIProvider, modelId: 'gpt-5.2', expectedName: 'GPT-5.2' },
     { provider: 'anthropic' as AIProvider, modelId: 'claude-sonnet-4-5', expectedName: 'Claude Sonnet 4.5' },
     { provider: 'google' as AIProvider, modelId: 'gemini-3-flash-preview', expectedName: 'Gemini 3 Flash Preview' },
     { provider: 'deepseek' as AIProvider, modelId: 'deepseek-chat', expectedName: 'DeepSeek Chat' },
   ]
   ```
   For each, assert `result?.name` equals `expectedName` and `result?.provider` equals `provider`.

### describe('getModelsForProvider') (AICB-04)

3. **Returns empty array for azure** -- Assert `getModelsForProvider('azure' as AIProvider)` `toHaveLength(0)`.

4. **Every model has required fields** -- For `openai` provider, assert every model in the array has `id`, `name`, `provider`, and `pricing` with `input` and `output` as numbers.
