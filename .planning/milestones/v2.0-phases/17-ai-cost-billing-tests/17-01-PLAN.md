### describe('calculateCostInDollars')

1. **Parametric provider coverage using it.each** (AICB-01):
   Use `it.each` with these test cases to verify correct cost for each provider:
   ```typescript
   const providerCases = [
     { provider: 'openai' as AIProvider, modelId: 'gpt-5-nano', inputPrice: 0.05, outputPrice: 0.40 },
     { provider: 'anthropic' as AIProvider, modelId: 'claude-3-haiku', inputPrice: 0.25, outputPrice: 1.25 },
     { provider: 'google' as AIProvider, modelId: 'gemini-2.0-flash', inputPrice: 0.10, outputPrice: 0.40 },
     { provider: 'deepseek' as AIProvider, modelId: 'deepseek-chat', inputPrice: 0.14, outputPrice: 0.28 },
   ]
   ```
   For each case, call `calculateCostInDollars({ promptTokens: 1_000_000, completionTokens: 1_000_000 }, provider, modelId)`.
   Assert result `toBeCloseTo(inputPrice + outputPrice, 6)`.

2. **Zero usage returns zero** -- Call with `{ promptTokens: 0, completionTokens: 0 }` for any provider. Assert result `toBe(0)`.

3. **Prompt-only usage** -- Call with `{ promptTokens: 1_000_000, completionTokens: 0 }` for `openai / gpt-5-nano`. Assert result `toBeCloseTo(0.05, 6)` (input price only).

4. **Completion-only usage** -- Call with `{ promptTokens: 0, completionTokens: 1_000_000 }` for `openai / gpt-5-nano`. Assert result `toBeCloseTo(0.40, 6)` (output price only).

5. **Falls back from promptTokens to inputTokens** -- Call with `{ inputTokens: 1_000_000, outputTokens: 1_000_000 }` (NO promptTokens/completionTokens set). Assert cost equals the same as using `promptTokens/completionTokens` with the same values.

6. **promptTokens takes priority over inputTokens** -- Call with `{ promptTokens: 1_000_000, inputTokens: 2_000_000, completionTokens: 0 }`. The cost should use promptTokens (1M), not inputTokens (2M). Assert `toBeCloseTo(0.05, 6)` for `openai / gpt-5-nano`.

7. **OpenRouter returns zero cost** -- Call with `{ promptTokens: 1_000_000, completionTokens: 1_000_000 }` for `openrouter / any-model`. Assert result `toBe(0)`.

8. **Unknown model returns zero cost** -- Call with `{ promptTokens: 1_000_000, completionTokens: 1_000_000 }` for `openai / nonexistent-model`. Assert result `toBe(0)`.

### describe('aggregateUsage')

2. **Single-item array returns identical usage** -- Call with `[{ promptTokens: 100, inputTokens: 100, completionTokens: 50, outputTokens: 50 }]`. Assert result matches the input usage object.

3. **Multiple items sum all fields correctly** -- Call with 3 usage objects having different values for all 4 fields. Assert each field in the result equals the sum of corresponding fields across all 3 inputs.

5. **Large token counts** -- Call with `[{ promptTokens: 10_000_000, completionTokens: 5_000_000 }, { promptTokens: 20_000_000, completionTokens: 15_000_000 }]`. Assert `promptTokens: 30_000_000, completionTokens: 20_000_000`. Ensures no overflow issues.

Use `toBeCloseTo` for all cost assertions. Use `toEqual` for aggregateUsage assertions (integer arithmetic, no floating point risk).
