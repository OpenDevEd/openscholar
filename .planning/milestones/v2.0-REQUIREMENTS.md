# Requirements: OpenAlex Count -- v2.0 TDD & Test Coverage

**Defined:** 2026-02-28
**Core Value:** Every major code path in search, AI, and user management has tests -- and every new feature is built test-first using strict red-green-refactor TDD.

## v2.0 Requirements

Requirements for this milestone. Each maps to roadmap phases.

### Test Infrastructure

- [x] **INFRA-01**: Vitest config updated with `environmentMatchGlobs` routing convex tests to edge-runtime, hook tests to jsdom, and all existing tests to node
- [x] **INFRA-02**: 7 new devDependencies installed (`convex-test`, `@edge-runtime/vm`, `@testing-library/react`, `@testing-library/user-event`, `@testing-library/jest-dom`, `jsdom`, `@vitejs/plugin-react`)
- [x] **INFRA-03**: Global test setup file (`tests/setup.ts`) with jest-dom matchers and RTL cleanup
- [x] **INFRA-04**: Convex test setup module (`convex/test.setup.ts`) for convex-test module discovery
- [x] **INFRA-05**: All 43 existing tests pass after infrastructure changes with zero modifications

### Search & Filters

- [x] **SRCH-01**: `createSearchParameters` correctly translates all filter combinations (field, year range, date range, cites, citedBy, relatedTo, region, countryFocus, reviewOnly) to OpenAlex API params
- [x] **SRCH-02**: Region codec (`encodeRegions`/`decodeRegions`) passes bijectivity test in both directions for all INTERNAL_TO_URL_CODE entries
- [x] **SRCH-03**: `buildFilterData` assembles correct filter sections for each filter type (search, time, geographic, content, ratings, citations)
- [x] **SRCH-04**: All filter active predicates (`isDateFilterActive`, `isRatingFilterActive`, `isCountryFilterActive`, `isCitesFilterActive`, `isCitedByFilterActive`, `isRelatedToFilterActive`, `isReviewFilterActive`) return correct boolean for active and inactive states
- [x] **SRCH-05**: `validateAndExpandKeywords` detects invalid queries (single char, unbalanced operators) and expands keyword bookmarks correctly
- [x] **SRCH-06**: URL param serialization (`serializeSearchParams`) round-trips correctly -- serialize then parse produces identical params

### Data Export

- [x] **EXPRT-01**: `jsonToCSV` produces correct CSV with proper headers, row values, and special character escaping
- [x] **EXPRT-02**: `exportToCSV` / `exportToJSON` include correct fields based on `ExportOptions` flags (includeMetadata, includeConfidence, includeReasoning, includeCitations)
- [x] **EXPRT-03**: `formatAnswerForCSV` and `formatAnswerForExcel` handle all answer types correctly (null, boolean, number, string, array)
- [x] **EXPRT-04**: `getStructuredCitations`, `getCitationStatus`, `getPrimaryCitation`, `getAllCitationLocations` return correct data and respect PDF feature flag gating
- [x] **EXPRT-05**: `downloadAll` and `downloadItem` produce correct output for both JSON and CSV formats with search metadata

### AI Prompts & Schemas

- [x] **AIPR-01**: All prompt builders (`buildEnhanceQueryPrompts`, `buildScreeningQuestionsPrompts`, `buildScreeningResponsesPrompts`, `buildTranslateQueryPrompts`, `buildTranslatePaperContentPrompts`, `buildExtractionQuestionsPrompts`) produce structurally correct prompts with required fields
- [x] **AIPR-02**: `validateQuery` detects unbalanced parentheses and trailing Boolean operators
- [x] **AIPR-03**: `repairJSON` and `repairSingleField` recover malformed AI responses for common failure patterns
- [x] **AIPR-04**: All Zod schemas (`queryEnhancementSchema`, `screeningQuestionsSchema`, dynamic `createScreeningResponsesSchema`) accept valid inputs and reject invalid ones
- [x] **AIPR-05**: `encodeQuestionKey` / `decodeQuestionKey` round-trip correctly for ASCII and non-ASCII question text
- [x] **AIPR-06**: `encodeQuestionResponseMap` / `decodeQuestionResponseMap` preserve all key-value pairs through round-trip encoding

### AI Batch Processing

- [x] **AIBP-01**: `processBatch` handles all-success scenario -- returns all results with correct `usageByItemId` accumulation
- [x] **AIBP-02**: `processBatch` handles all-fail scenario -- returns empty results with all errors captured
- [x] **AIBP-03**: `processBatch` handles partial-failure scenario -- returns successful results while capturing errors for failed items
- [x] **AIBP-04**: `processScreeningBatch` maps papers to screening configs correctly and passes through question context
- [x] **AIBP-05**: `processTranslationBatch` passes target language through to each translation call
- [x] **AIBP-06**: `generateMissingScreeningCombinationsByPaper` correctly identifies which (paper, question) pairs lack responses

### AI Cost & Billing

- [x] **AICB-01**: `calculateCostInDollars` returns correct cost for each provider's pricing model (OpenAI, Anthropic, Google, DeepSeek)
- [x] **AICB-02**: `aggregateUsage` correctly sums token counts across multiple usage objects
- [x] **AICB-03**: `getModelPricing` returns `{0, 0}` for unknown models and correct pricing for known models
- [x] **AICB-04**: `getModelById`, `getModelsForProvider`, `getDefaultModelForProvider` return correct model configs

### User Auth & State Machine

- [x] **AUTH-01**: `assertActiveUser` allows active users, throws FORBIDDEN for suspended users, throws FORBIDDEN for deleted users
- [x] **AUTH-02**: `createUserWithDefaults` atomically creates user row, credits row (freeBalance=2000), and subscription row (plan=free, status=active)
- [x] **AUTH-03**: `ensureUser` creates new user on first login and updates `lastLoginAt` on return visits without overwriting existing profile fields
- [x] **AUTH-04**: `syncProfileFromSession` only patches blank profile fields and does not overwrite existing values

### Plan Enforcement & Feature Gating

- [x] **PLAN-01**: `PLAN_CONFIG` shape contract -- correct credit amounts and tier values for all four plans (free, go, pro, enterprise)
- [x] **PLAN-02**: `getPlanTier`, `getFreeCreditCapForPlan`, `getPlanFromPriceId` return correct values for all plan types
- [x] **PLAN-03**: `requirePlanTier` throws `EXTRACTION_PLAN_REQUIRED` when user tier is below minimum
- [x] **PLAN-04**: All server-side feature flag guards (`requireCreditsEnabled`, `requireCreditTopupsEnabled`, `requireSubscriptionsEnabled`) throw when disabled and pass when enabled
- [x] **PLAN-05**: `selectCanonicalSubscription` returns correct subscription when multiple rows exist (priority ordering)

## Out of Scope

| Feature | Reason |
|---------|--------|
| E2E tests for search/extraction flows | Playwright search suite is a separate milestone -- this focuses on unit + integration |
| React component rendering tests | Component tests require extensive mock setup with diminishing returns vs E2E |
| `convex-test` end-to-end auth-gated functions | Blocked by convex-test issue #50 (`getUserIdentity` bug) |
| TDD for features not yet built | TDD workflow established but applied to future milestones, not retroactively |
| CI pipeline changes for new tests | New tests run under existing `vitest` command -- no CI changes needed |
| Visual regression tests | Separate concern, notoriously flaky |
