<objective>
Fix orphan diffs on job deletion, surface diff truncation metadata, and extend GDPR user cleanup.

Purpose: Three data integrity issues: (1) deleting a job leaves orphaned `extractionRunDiffs` where the deleted job was the baseline, (2) diff truncation at 1000 changes is silent -- users don't know their diff is incomplete, (3) `cleanupDeletedUsers` only deletes API keys, leaving extraction data and Zotero connections behind for deleted users.

Output: Step 8b in cascade delete for baseline diffs, schema + mutation changes for truncation metadata with UI banner, and extended user cleanup with extraction job cascade and Zotero connection deletion.
</objective>
