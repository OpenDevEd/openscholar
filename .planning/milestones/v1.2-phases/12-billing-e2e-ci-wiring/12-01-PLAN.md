Add environment variables and steps to three billing CI jobs across two workflow files.

**Environment variables to add to all three billing CI job env blocks:**

```yaml
CLERK_SECRET_KEY: ${{ secrets.CLERK_SECRET_KEY }}
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY: ${{ secrets.NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY }}
NEXT_PUBLIC_CLERK_SIGN_IN_URL: /sign-in
NEXT_PUBLIC_CLERK_SIGN_UP_URL: /sign-up
E2E_CLERK_USER_EMAIL: ${{ secrets.E2E_CLERK_USER_EMAIL }}
E2E_CLERK_USER_PASSWORD: ${{ secrets.E2E_CLERK_USER_PASSWORD }}
E2E_BASE_URL: http://127.0.0.1:3000
```

Why each env var is needed:
- `CLERK_SECRET_KEY`: Required by the billing fixture (`e2e/billing/fixtures.ts`) to create/delete Clerk test users via `@clerk/backend` API
- `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`: Required by the Next.js server (webServer block) to boot without errors and by Clerk middleware
- `NEXT_PUBLIC_CLERK_SIGN_IN_URL` and `NEXT_PUBLIC_CLERK_SIGN_UP_URL`: Static route values (`/sign-in`, `/sign-up`) required by Next.js server build
- `E2E_CLERK_USER_EMAIL` and `E2E_CLERK_USER_PASSWORD`: Required by `globalSetup` (`e2e/global.setup.ts`) which calls `ensureDisposableClerkUser()` unconditionally — it runs for ALL Playwright invocations regardless of selected project
- `E2E_BASE_URL`: Read by `playwright.config.ts` for the webServer base URL

**Steps to append after the existing upload-artifact step in each billing CI job:**

```yaml
- name: Install Playwright browser
  run: npx playwright install --with-deps chromium

- name: Run billing E2E tests
  run: npm run test:billing:e2e

- name: Upload billing E2E report
  if: always()
  uses: actions/upload-artifact@v4
  with:
    name: billing-e2e-report-${{ github.job }}
    path: playwright-report
    if-no-files-found: ignore
```

The artifact name uses `${{ github.job }}` to avoid name conflicts between the three billing jobs uploading to the same workflow run.
