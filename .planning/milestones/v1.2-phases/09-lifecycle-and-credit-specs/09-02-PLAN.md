This function creates a PaymentIntent directly via the Stripe API with the `credit_topup` metadata, bypassing Stripe Checkout (which is a hosted page and cannot be automated). When confirmed, the PaymentIntent triggers a `payment_intent.succeeded` webhook which calls `grantPurchasedCreditsFromPaymentIntent` in Convex to grant the credits.

```typescript
/**
 * Purchase credits via checkout-bypass pattern (PaymentIntent direct).
 * Creates a confirmed PaymentIntent with credit_topup metadata,
 * bypassing Stripe Checkout (hosted page that cannot be automated).
 *
 * The `payment_intent.succeeded` webhook triggers `grantPurchasedCreditsFromPaymentIntent`
 * in Convex, which grants credits based on the metadata.
 */
export async function createTopupBypass(args: {
  stripe: Stripe;
  customerId: string;
  paymentMethodId: string;
  userId: string;
  credits?: number;
  amountCents?: number;
}): Promise<{ paymentIntentId: string }> {
  const credits = args.credits ?? 10_000;
  const amountCents = args.amountCents ?? 100;

  const pi = await args.stripe.paymentIntents.create({
    amount: amountCents,
    currency: "usd",
    customer: args.customerId,
    payment_method: args.paymentMethodId,
    metadata: {
      billingType: "credit_topup",
      userId: args.userId,
      credits: String(credits),
      bundleKey: `credits_${credits}`,
      amountCents: String(amountCents),
      creditsPerUsd: "10000",
    },
    confirm: true,
    off_session: true,
  });

  return { paymentIntentId: pi.id };
}
```

Key points:
- Defaults to 10,000 credits at $1.00 (100 cents) -- the smallest bundle
- Metadata format MUST match exactly what `grantPurchasedCreditsFromPaymentIntent` expects:
  - `billingType: "credit_topup"` (checked with strict equality)
  - `credits` as a string (parsed to integer)
  - `userId` as the Convex user ID
- `confirm: true` and `off_session: true` ensure the PaymentIntent is immediately confirmed with the test payment method
- Do NOT modify any existing functions in the file

**Test 2: "upgrade Go to Pro grants pro-rata credits" (CRED-03)**

```typescript
test("upgrade Go to Pro grants pro-rata credits", async ({
  clerkUser,
  stripeClient,
  webhookWaiter,
  billingPage,
  pricingPage,
}) => {
  const goPriceId = process.env.STRIPE_GO_PRICE_ID!;

  // 1. Subscribe to Go via checkout-bypass
  const { customerId, subscriptionId } = await createSubscriptionBypass({
    stripe: stripeClient,
    email: clerkUser.email,
    userId: webhookWaiter.userId,
    priceId: goPriceId,
  });
  await webhookWaiter.waitForSubscriptionPlan("go");
  await webhookWaiter.waitForCreditBalance((total) => total >= 5_000);

  // 2. Read subscription timestamps for pro-rata calculation
  const subscription = await stripeClient.subscriptions.retrieve(subscriptionId);
  const periodStart = subscription.current_period_start * 1000; // Convert to ms
  const periodEnd = subscription.current_period_end * 1000;

  // 3. Upgrade to Pro via pricing page confirmation dialog
  await pricingPage.goto();
  await pricingPage.clickSubscribe("pro");
  await expect(pricingPage.upgradeConfirmButton).toBeVisible({ timeout: 15_000 });
  await pricingPage.upgradeConfirmButton.click();

  // 4. Wait for Pro subscription in Convex
  await webhookWaiter.waitForSubscriptionPlan("pro");

  // 5. Calculate expected pro-rata credits
  //    The server calculates: floor(remainingRatio * creditDelta)
  //    where remainingRatio = (periodEnd - now) / (periodEnd - periodStart)
  //    and creditDelta = 15,000 - 3,000 = 12,000
  const now = Date.now();
  const remainingRatio = (periodEnd - now) / (periodEnd - periodStart);
  const expectedProRata = Math.floor(remainingRatio * 12_000);
  const expectedTotal = 2_000 + 3_000 + expectedProRata; // free + Go + proRata

  // 6. Wait for credits to be updated (pro-rata grant may arrive after plan change)
  await webhookWaiter.waitForCreditBalance(
    (total) => total >= expectedTotal - 2,
  );

  // 7. Assert billing page shows correct balance within +-2 tolerance
  //    (tolerance accounts for timing difference between test and server calculation)
  await billingPage.goto();
  const credits = await billingPage.getCreditBalance();
  expect(credits).toBeGreaterThanOrEqual(expectedTotal - 2);
  expect(credits).toBeLessThanOrEqual(expectedTotal + 2);

  // 8. Cleanup
  await cleanupStripeCustomer({ stripe: stripeClient, customerId });
});
```

Key notes for pro-rata test:
- Read `current_period_start` and `current_period_end` from the Stripe subscription BEFORE triggering the upgrade
- Calculate expected pro-rata AFTER the upgrade completes (using `Date.now()` at that point)
- Use +-2 tolerance (not +-1) per Pitfall 6 in research -- accounts for timing gap between test calculation and server's `grantUpgradeProRataCredits` mutation
- `expectedTotal = 2,000 (free) + 3,000 (Go grant) + expectedProRata`
