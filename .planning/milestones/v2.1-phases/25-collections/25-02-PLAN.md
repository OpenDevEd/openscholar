- Returns: `v.null()`
- Verify collection ownership (fetch + check userId, throw FORBIDDEN if mismatch)
- Verify library item ownership (fetch + check userId, throw FORBIDDEN if mismatch)
- Check for existing junction row via `by_collection_item` compound index + `.unique()`
- If existing, return null (idempotent no-op)
- Otherwise insert into `libraryItemCollections` with userId, collectionId, libraryItemId, assignedAt: Date.now()

**removeFromCollection mutation:**
- Args: `{ collectionId: v.id("collections"), libraryItemId: v.id("libraryItems") }`
- Returns: `v.null()`
- Verify collection ownership (throw FORBIDDEN if mismatch)
- Query junction row via `by_collection_item` compound index + `.unique()`
- If found, delete it. If not found, return null (no-op).

**getCollectionsWithCounts query:**
- Args: `{}`
- Returns: array of objects with `_id`, `name`, `createdAt`, `updatedAt`, `itemCount`
- Fetch all user collections via `by_user` index → `.collect()`
- For each collection, count junction rows via `by_collection` index → `.collect().length`
- Sort alphabetically by name (case-insensitive)
- Return array of `{ ...collection, itemCount }`

**getItemCollections query:**
- Args: `{ libraryItemId: v.id("libraryItems") }`
- Returns: array of collection IDs
- Query `libraryItemCollections` by `by_item` index → `.collect()`
- Return array of `collectionId` values
