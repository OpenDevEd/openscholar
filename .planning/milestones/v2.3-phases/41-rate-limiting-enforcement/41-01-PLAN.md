5. **Add `consume` internal mutation** for action endpoints that lack `ctx.db`:

```typescript
export const consume = internalMutation({
  args: {
    name: v.string(),
    key: v.string(),
    count: v.optional(v.number()),
  },
  returns: v.null(),
  handler: async (ctx, args) => {
    await rateLimit(ctx, {
      name: args.name as any,
      key: args.key,
      count: args.count,
      throws: true,
    });
    return null;
  },
});
```

The `as any` cast on `args.name` is needed because `args.name` is `string` but `rateLimit` expects the union of defined rate limit names. This is safe because invalid names will cause a runtime error from convex-helpers, and this internal mutation is only called by our own code with correct names.

**Delete everything from the old stub** -- the `RateLimitConfig` type, `RATE_LIMITS` record, implementation notes comment, and `getRateLimitConfig` function. None of these are imported anywhere.
