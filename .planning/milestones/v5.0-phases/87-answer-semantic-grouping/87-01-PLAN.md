  <behavior>
    ### buildSynonymMap()
    - Returns `Map<string, string>` where each synonym maps to its canonical key
    - Boolean "yes" group: 'yes', 'true', 'positive', 'affirmative' → all map to 'yes'
    - Boolean "no" group: 'no', 'false', 'negative', 'incorrect' → all map to 'no'
    - Null/missing group: 'n/a', 'na', 'not applicable', 'unknown', 'none', 'no data', 'not available', '—' → all map to 'n/a'
    - Singular/plural pairs are NOT grouped (e.g., 'model' and 'models' remain separate)
    - Keys not in the map are implicitly self-mapping (groupKey = normalized)

    ### groupAnswersBySynonym(answers, synonymMap)
    - Input: `AnswerBucket[]` (each has `normalized`, `display`, `count`, optional `citationStatusMix`)
    - Groups by: `synonymMap.get(answer.normalized) ?? answer.normalized`
    - Uses NORMALIZED key for grouping (not display string) per CONTEXT.md locked decision
    - Groups with only 1 variant: `variants.length === 1` (used by GroupedAnswerRow to skip disclosure)
    - Representative = variant with highest count (ties: first encountered)
    - Group `count` = sum of variant counts (not just representative count)
    - Group `citationStatusMix` = sum of variant citationStatusMix per status key
    - Empty citationStatusMix defaults to `{ grounded: 0, best_effort: 0, insufficient_evidence: 0, extraction_error: 0 }`
    - Output sorted by group count descending (highest-count group first)
    - Variants within each group sorted by count descending

    ### mergeDisagreementClusters(clusters, synonymMap)
    - Input: `DisagreementCluster[]`, `SynonymMap`
    - Groups clusters by: `synonymMap.get(cluster.normalizedAnswer) ?? cluster.normalizedAnswer`
    - Single cluster per group: returned as-is (no merging needed)
    - Multiple clusters merged into one: normalizedAnswer = groupKey, displayAnswer from highest-count cluster
    - Merged count = sum of cluster counts
    - Merged avgConfidence = weighted average by count
    - Merged citationStatusMix = sum per key across all clusters
    - Merged examples = concatenated from all clusters (all examples, not just 5)
    - Output sorted by count descending

    ### Test cases to implement (RED phase — write these first, all must fail):
    - buildSynonymMap returns expected canonical keys for all synonym entries
    - Answers not in map map to themselves (no accidental grouping)
    - groupAnswersBySynonym groups 'Yes', 'yes', 'True' into single group
    - groupAnswersBySynonym counts = sum of variant counts (e.g., 5+3+2=10)
    - groupAnswersBySynonym citationStatusMix aggregates correctly (not just representative's mix)
    - groupAnswersBySynonym single-variant groups have variants.length === 1
    - groupAnswersBySynonym representative is highest-count variant
    - mergeDisagreementClusters merges 'yes' and 'true' clusters into one
    - mergeDisagreementClusters merged examples includes examples from both originals
    - mergeDisagreementClusters single-cluster groups returned unchanged
    - Edge: empty input array returns empty output
    - Edge: all answers unique → each in its own group
