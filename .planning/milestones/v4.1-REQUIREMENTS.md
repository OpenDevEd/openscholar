# Requirements: OpenAlex Count — Screening Export

**Defined:** 2026-03-09
**Core Value:** Reliable, well-tested academic search and AI extraction

## v4.1 Requirements

Requirements for screening export milestone. Each maps to roadmap phases.

### Export Data

- [x] **EXP-01**: User can fetch all screening results for a completed job via auth-gated query
- [x] **EXP-02**: User can export screening results as CSV with paper metadata, question answer columns, score, stars, and qualified status
- [x] **EXP-03**: User can export screening results as JSON with structured paper data, answers, and scoring
- [x] **EXP-04**: User can export screening results as XLSX with results sheet and summary sheet (job config, scoring rules, statistics)
- [x] **EXP-05**: Export handles failed/skipped papers gracefully with null fallbacks for missing answer columns

### Scoring Simplification

- [x] **SCORE-01**: Star thresholds use only minScore (maxScore field removed from schema, validators, scoring engine, and UI)
- [x] **SCORE-02**: Star rating assignment uses highest-matching-minScore-wins logic (thresholds sorted descending, first match returns)
- [x] **SCORE-03**: Existing screening jobs with maxScore in stored data continue to work (backward-compatible read)

### UI Integration

- [x] **UI-01**: User sees an export button on completed screening job cards in job history
- [x] **UI-02**: User can select export format (CSV, JSON, XLSX) from a dropdown menu
- [x] **UI-03**: User sees a loading state while export file is being generated
- [x] **UI-04**: Exported files have descriptive filenames including job date and status
- [x] **UI-05**: User sees a warning when exporting results from cancelled or incomplete jobs
- [x] **UI-06**: Export UI is translated across all 6 supported locales

## Future Requirements

None — this is a focused enhancement milestone.

## Out of Scope

| Feature | Reason |
|---------|--------|
| AI reasoning/confidence in export | User scoped to core results only (metadata + answers + score + stars + qualified) |
| Server-side export generation | Max 200 papers per job; client-side generation is sufficient |
| Export from search results directly | Separate feature; screening export is from job history |
| Bulk export across multiple jobs | Single-job export covers the use case |
| Email/share export link | Download-only for now |
