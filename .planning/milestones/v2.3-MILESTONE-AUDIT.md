## Integration Findings

### FINDING-01: New `as any` in rateLimit.ts (Low severity)

- **File:** `convex/lib/rateLimit.ts:52`
- **Pattern:** `name: args.name as any` — workaround for `defineRateLimits` type constraint
- **Impact:** No runtime impact. All callers pass valid limit names.
- **Fix:** Cast to `Parameters<typeof rateLimit>[1]['name']` instead of `any`

### FINDING-02: Cascade scope excludes templates (Informational)

- **Context:** `deleteExtractionInternal` covers 8 job-scoped child tables but not `extractionWorkflowTemplates`
- **Verdict:** Correct by design — templates are user-scoped (`by_user` index), not job children
- **Impact:** None. No action required.
