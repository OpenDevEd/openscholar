<feature>
  <name>Scoring Engine</name>
  <files>convex/screening/scoring.ts, convex/screening/scoring.test.ts</files>
  <behavior>
    **computeScore(answers, rules) -> number:**
    - { q1: true, q2: true } with rules [q1: yes=2, no=-1, null=0; q2: yes=1, no=0, null=-1] -> 3
    - { q1: false, q2: false } with same rules -> -1
    - { q1: null, q2: null } -> -1 (0 + -1)
    - {} (empty answers) -> -1 (nullPoints for both: 0 + -1)
    - { q1: true, q2: true, q99: false } -> 3 (q99 ignored, no matching rule)
    - any answers with [] (empty rules) -> 0
    - { q1: true, q2: false } -> 2 (2 + 0)

    **computeStarRating(score, thresholds) -> number:**
    - score=5, thresholds=[{min:0,max:2,stars:1},{min:3,max:5,stars:2}] -> 2
    - score=0, same thresholds -> 1
    - score=4, thresholds=[{min:0,max:3,stars:1},{min:5,max:10,stars:2}] -> 0 (gap at 4)
    - score=-5, thresholds starting at min=0 -> 0 (no negative coverage)
    - score=4, thresholds=[{min:0,max:5,stars:1},{min:3,max:8,stars:2}] -> 1 (first match wins)
    - score=3, threshold with stars=7 -> clamped to 5
    - score=3, threshold with stars=-2 -> clamped to 0
    - score=5, empty thresholds -> 0

    **isQualified(score, minimumScore) -> boolean:**
    - score=5, minimumScore=3 -> true
    - score=2, minimumScore=3 -> false
    - score=3, minimumScore=3 -> true (equal qualifies)
    - score=5, minimumScore=undefined -> true (all qualify)
    - score=-10, minimumScore=undefined -> true

    **scorePaper(answers, config) -> ScoringResult:**
    - All-yes answers -> { score: 6, stars: 3, qualified: true }
    - Mixed answers -> { score: 1, stars: 1, qualified: false }
    - All-null answers -> { score: -1, stars: 0, qualified: false }
    - Missing answer key treated as null -> correct score

    **validateScoringConfig(config) -> ConfigValidationWarning[]:**
    - stars=7 -> warning "star_out_of_range"
    - stars=2.5 (non-integer) -> warning "star_out_of_range"
    - rules with negative points but no negative threshold coverage -> warning "missing_negative_coverage"
    - valid config -> empty warnings array
  </behavior>
  <implementation>
    Create pure TypeScript functions in convex/screening/scoring.ts matching the exact signatures and behavior from the research doc (76-RESEARCH.md "Pattern 1: Pure Scoring Function Module"). Key implementation details:

    1. Define TypeScript interfaces: ScoringRule, StarThreshold, ScoringConfig, ScoringResult, ConfigValidationWarning
    2. computeScore: Loop over rules, lookup answer by questionKey, add yesPoints/noPoints/nullPoints. Missing/undefined answers use nullPoints.
    3. computeStarRating: Loop over thresholds in order, return first match where minScore <= score <= maxScore. Clamp result to Math.max(0, Math.min(5, stars)). Return 0 if no match.
    4. isQualified: Return true if minimumScore is undefined/null, else score >= minimumScore.
    5. scorePaper: Compose the three functions above, return { score, stars, qualified }.
    6. validateScoringConfig: Check stars in 0-5 integer range, check negative score coverage. Return warnings array (not errors -- engine works with any config).

    Do NOT import from convex/server or take ctx parameters. These are pure functions with zero Convex dependency.
  </implementation>
</feature>
