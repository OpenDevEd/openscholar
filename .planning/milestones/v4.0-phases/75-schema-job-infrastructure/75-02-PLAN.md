Create `convex/screening/mutations.ts` with:

```typescript
export const createScreeningJob = mutation({
  args: {
    papers: v.array(screeningPaperInputValidator),
    questions: v.array(screeningQuestionValidator),
    scoringConfig: screeningScoringConfigValidator,
    targetCollectionId: v.optional(v.id("collections")),
  },
  returns: v.object({ jobId: v.id("screeningJobs") }),
  handler: async (ctx, args) => { ... }
});
```

Handler logic:
1. `requireAuth(ctx)` for authentication
2. Validate papers.length > 0 and <= MAX_SCREENING_PAPERS_PER_JOB
3. Check for active job: query `screeningJobs` by_user_status for "pending", then for "processing" (two queries per Pitfall 3 in RESEARCH.md)
4. Credit pre-flight: query credits by_user, check (freeBalance + paidBalance) >= papers.length. Throw INSUFFICIENT_CREDITS if not.
5. Insert screeningJobs record with status="pending", processedPapers=0, failedPapers=0, qualifiedPapers=0, embedded questions and scoringConfig, createdAt/updatedAt=Date.now()
6. Insert screeningResults records for each paper with status="pending", createdAt=Date.now()
7. Return { jobId }

Note: Do NOT start a workflow in this phase. The workflow start will be added in Phase 77. The job stays in "pending" status until the workflow is wired.
