**Part A: Create `convex/screening/workflow.ts`**

New file. Import: `workflow` from `"../workflow"`, `v` from `"convex/values"`, `internal` from `"../_generated/api"`.

Define and export `runScreeningWorkflow` using `workflow.define`:

```
args: { jobId: v.id("screeningJobs") }
```

Handler (following the extraction workflow pattern):

1. **Load job**: `const job = await step.runQuery(internal.screening.queries.getJobInternal, { jobId })`. If not found, throw error.

2. **Load pending results**: `const pendingResults = await step.runQuery(internal.screening.queries.getPendingResults, { jobId })`. If empty, mark job as completed immediately (edge case: all papers somehow already processed).

3. **Update status to processing**: `await step.runMutation(internal.screening.mutations.updateJobStatus, { jobId, status: "processing" })`.

4. **Enqueue each paper**: Loop over `pendingResults` and for each:
   ```typescript
   await step.runMutation(internal.screening.mutations.enqueueScreeningPaper, {
     resultId: result._id,
     jobId,
   });
   ```

5. Log completion: `console.log("[ScreeningWorkflow] Enqueued ${pendingResults.length} papers for screening")`.

The workflow ends after enqueuing. Papers are processed asynchronously by the workpool. The onComplete handler (Plan 01) handles scoring, library save, and finalization.
