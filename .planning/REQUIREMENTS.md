## Future Requirements

None — this milestone completes the type safety initiative.

## Out of Scope

| Feature | Reason |
|---------|--------|
| Fixing `convex/_generated/api.d.ts` any types | Auto-generated by Convex CLI, not user-controlled |
| Enabling `strict: true` in tsconfig | May cascade unrelated errors; separate concern |
| Adding ESLint `no-explicit-any` rule | Enforcement rule is a follow-up after code is clean |
| Refactoring code structure | Type-only changes; no behavioral modifications |
