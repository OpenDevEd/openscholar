### Integration Findings (Non-blocking)

**STRIPE_PRO_PRICE_ID_PREFLIGHT:** The `billing-live` preflight validation (ci.yml lines 140-156) guards `STRIPE_GO_PRICE_ID` but not `STRIPE_PRO_PRICE_ID`. Tests using the Pro price ID get `undefined` from `process.env.STRIPE_PRO_PRICE_ID!` and produce a Stripe API error rather than a fast-fail. Same gap in `billing-nightly.yml`. Affects SUB-02, CRED-02.

**BILLING_EXTENDED_NO_PREFLIGHT:** The `billing-live-extended` job has no secrets validation step. If Stripe/Convex secrets are absent, E2E tests fail with confusing runtime errors instead of a clear preflight message.

**DEAD_POM_LOCATORS:** `BillingPage` declares `freeCredits` and `paidCredits` locators (billing-page.ts lines 20-21) targeting existing testids in `credit-balance-card.tsx`, but no spec file asserts on them. Dead code.
