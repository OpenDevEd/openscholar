# Cookie政策

## Openscholar.ai如何使用Cookie

当您浏览openscholar.ai时，称为Cookie的小型数据文件可能会存储在您的设备上。这些文件有助于网站正常运作，并向网站所有者提供关于其网站使用情况的洞察。以下我们将解释openscholar.ai使用哪些Cookie及其用途。

## 严格必要的Cookie

| **名称** | **用途** | **有效期** |
| --- | --- | --- |
| `__session`, `__client_uat`, `__client` | 保持您的登录状态 | 最长 1 年 |
| `NEXT_LOCALE` | 记住您的语言 | 1 年 |
| `__cf_bm`, `_cfuvid` | Cloudflare 用其保护网站免受自动化流量影响 | 30 分钟，或直到您关闭浏览器 |

您的 Cookie 选择保存在名为 openscholar_consent 的 Cookie 中。该 Cookie 设置在 openscholar.ai 上，因此同一选择适用于所有 Openscholar 网站以及所有使用 openscholar.ai 地址的社区。显示设置（如打开的面板）保存在浏览器的本地存储中。

## 性能和分析Cookie（可选）

| **名称** | **用途** | **有效期** |
| --- | --- | --- |
| `ph_phc_[token]_posthog`, `ph_phc_[token]_posthog_cpm` | 我们使用 PostHog 了解 Openscholar 的使用情况并修复问题。这些 Cookie 包含随机设备 ID、您的会话详情和您首次到达的页面。如果您登录，其中还包含您的账户 ID，PostHog 会将您的活动与您的姓名和电子邮箱关联。我们绝不出售您的信息。 | 365天 |
| `_ga`, `_ga_[id]` | 我们使用 Google Analytics 了解访问人数及其到达方式。这些 Cookie 包含随机 ID 和您的会话详情。 | 400天 |

### PostHog Cookie包含哪些数据？

PostHog Cookie以结构化格式保存以下详情：

- **$device_id**：分配给您设备的唯一随机代码（UUID）
- **distinct_id**：用于跟踪的匿名标识符。最初与您的device_id相同，但如果您登录可能会关联到您的账户
- **$sesid**：关于您当前浏览会话的详情，包括会话开始时间、唯一会话标识符以及最近活动的时间戳
- **$epp**：PostHog用于内部功能的技术标志
- **$initial_person_info**：记录您如何到达我们的网站（例如来自搜索引擎或直接访问）以及您首先着陆的页面

此 Cookie 不包含您的姓名、电子邮箱或其他私人信息。

### PostHog收集的其他数据

除Cookie本身外，PostHog还会自动收集补充信息：

**关于您设备和浏览器的技术详情：**
- 您使用的浏览器及其版本号
- 您设备的操作系统
- 您使用的是桌面电脑、手机还是平板电脑
- 您屏幕的显示分辨率
- 浏览器技术识别字符串（用户代理）

**大致地理信息：**
- 您的IP地址（仅用于估算位置，不保存在Cookie中）
- 般位置如国家、城市或地区（根据IP地址计算）
- 您的本地时区设置

**您如何浏览我们的网站：**
- 您在访问期间查看的页面
- 您来自的网站（引荐来源）
- 您点击的元素，例如按钮或链接
- 您在每个页面上阅读的时长
- 您向下滚动页面的距离

**我们特意排除的信息：**
- 您在表单中输入的文本，搜索内容除外
- 登录凭据或密码
- 付款或信用卡详细信息
- 任何其他私人或敏感个人信息
- 不使用第三方广告Cookie
- 您的数据永远不会出售给广告商或营销公司

### Google Analytics

如果您接受，Google Analytics 会接收您访问的页面、您到达本站的方式、设备类型和大致位置。它不会接收您的搜索内容，其广告功能已关闭。如果您改变主意，我们会停止它并删除其 Cookie。

### 如果您不接受

在您作出选择之前，或如果您拒绝分析 Cookie，我们只统计访问量，不使用 Cookie，除您的选择外也不在您的设备上存储任何内容：页面、您来自的网站、浏览器类型，以及运行搜索等操作。我们不记录您的点击、输入内容、位置或账户。您的 IP 地址和浏览器类型会变成每天更换的代码，我们不保留您的 IP 地址。

## 管理您的Cookie偏好设置

您可以随时点击openscholar.ai每个页面底部提供的"Cookie 偏好设置"链接来更新您的Cookie偏好设置。

此外，所有主流网页浏览器都提供用于控制Cookie的设置。如需了解关于Cookie的全面信息以及如何查看存储在您设备上的Cookie，请访问[www.aboutcookies.org](http://www.aboutcookies.org/)或[www.allaboutcookies.org](http://www.allaboutcookies.org/)。

### 从您的设备中移除Openscholar.ai Cookie

您可以随时使用浏览器的设置来移除我们的分析Cookie：

**Google Chrome：**
1. 选择右上角的三点菜单（⋮）
2. 进入设置 → 隐私和安全 → Cookie和网站数据
3. 选择"查看所有Cookie和网站数据"
4. 在搜索框中输入"openscholar.ai"
5. 点击PostHog Cookie旁边的删除图标

**Mozilla Firefox：**
1. 打开菜单（≡）并选择设置
2. 进入隐私与安全 → Cookie和网站数据
3. 选择"管理数据"
4. 输入"openscholar.ai"查找Cookie
5. 选中它并选择"移除所选"

**Apple Safari：**
1. 打开Safari → 偏好设置 → 隐私
2. 选择"管理网站数据"
3. 在搜索字段中输入"openscholar.ai"
4. 选择该条目并选择"移除"

**Microsoft Edge：**
1. 点击右上角的三点菜单（⋯）
2. 进入设置 → Cookie和网站权限 → Cookie和网站数据
3. 选择"查看所有Cookie和网站数据"
4. 搜索"openscholar.ai"
5. 点击删除图标

### 阻止分析Cookie被设置

如果您希望阻止我们创建分析Cookie：

1. **禁用所有Cookie**：将浏览器配置为拒绝所有Cookie（注意：这可能会影响其他网站的运行）
2. **仅阻止第三方Cookie**：这将阻止外部跟踪器，同时允许我们的第一方分析Cookie——这不会阻止openscholar.ai的Cookie
3. **安装隐私浏览器扩展**：Privacy Badger或uBlock Origin等隐私工具可以阻止分析Cookie
4. **启用"请勿跟踪"**：虽然openscholar.ai目前不响应DNT信号，但您可以在浏览器设置中激活此选项
5. **使用我们的Cookie设置**：点击任何openscholar.ai页面底部的"Cookie 偏好设置"来调整您的偏好设置
