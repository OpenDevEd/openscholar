# Cookie政策

## OpenScholar.ai如何使用Cookie

当您浏览openscholar.ai时，称为Cookie的小型数据文件可能会存储在您的设备上。这些文件有助于网站正常运作，并向网站所有者提供关于其网站使用情况的洞察。以下我们将解释openscholar.ai使用哪些Cookie及其用途。

## 严格必要的Cookie

OpenScholar.ai目前未设置任何网站运行所需的Cookie。

## 性能和分析Cookie（可选）

| **名称** | **用途** | **有效期** |
| --- | --- | --- |
| ph_phc_[token]_posthog | 我们使用PostHog分析软件来了解用户如何与我们的网站互动。这帮助我们创建更好的报告并提升用户体验。该Cookie包含匿名设备标识符、您的浏览会话详情以及您最初到达的页面。所有数据均为匿名收集——我们永远不会识别您的个人身份。OpenScholar.ai不使用第三方跟踪技术，也不会将您的信息出售给广告公司。 | 365天 |

### PostHog Cookie包含哪些数据？

PostHog Cookie以结构化格式保存以下详情：

- **$device_id**：分配给您设备的唯一随机代码（UUID）
- **distinct_id**：用于跟踪的匿名标识符。最初与您的device_id相同，但如果您登录可能会关联到您的账户
- **$sesid**：关于您当前浏览会话的详情，包括会话开始时间、唯一会话标识符以及最近活动的时间戳
- **$epp**：PostHog用于内部功能的技术标志
- **$initial_person_info**：记录您如何到达我们的网站（例如来自搜索引擎或直接访问）以及您首先着陆的页面

此Cookie不包含任何可识别您个人身份的信息，例如您的姓名、电子邮件或其他私人详细信息。

### PostHog收集的其他数据

除Cookie本身外，PostHog还会自动收集补充信息：

**关于您设备和浏览器的技术详情：**
- 您使用的浏览器及其版本号
- 您设备的操作系统
- 您使用的是桌面电脑、手机还是平板电脑
- 您屏幕的显示分辨率
- 浏览器技术识别字符串（用户代理）

**大致地理信息：**
- 您的IP地址（仅用于估算位置，不保存在Cookie中）
- 般位置如国家、城市或地区（根据IP地址计算）
- 您的本地时区设置

**您如何浏览我们的网站：**
- 您在访问期间查看的页面
- 您来自的网站（引荐来源）
- 您点击的元素，例如按钮或链接
- 您在每个页面上阅读的时长
- 您向下滚动页面的距离

**我们特意排除的信息：**
- 您在表单中输入的文字
- 登录凭据或密码
- 付款或信用卡详细信息
- 任何其他私人或敏感个人信息
- 不使用第三方广告Cookie
- 您的数据永远不会出售给广告商或营销公司

## 管理您的Cookie偏好设置

您可以随时点击openscholar.ai每个页面底部提供的"Cookie设置"链接来更新您的Cookie偏好设置。

此外，所有主流网页浏览器都提供用于控制Cookie的设置。如需了解关于Cookie的全面信息以及如何查看存储在您设备上的Cookie，请访问[www.aboutcookies.org](http://www.aboutcookies.org/)或[www.allaboutcookies.org](http://www.allaboutcookies.org/)。

### 从您的设备中移除OpenScholar.ai Cookie

您可以随时使用浏览器的设置来移除我们的分析Cookie：

**Google Chrome：**
1. 选择右上角的三点菜单（⋮）
2. 进入设置 → 隐私和安全 → Cookie和网站数据
3. 选择"查看所有Cookie和网站数据"
4. 在搜索框中输入"openscholar.ai"
5. 点击PostHog Cookie旁边的删除图标

**Mozilla Firefox：**
1. 打开菜单（≡）并选择设置
2. 进入隐私与安全 → Cookie和网站数据
3. 选择"管理数据"
4. 输入"openscholar.ai"查找Cookie
5. 选中它并选择"移除所选"

**Apple Safari：**
1. 打开Safari → 偏好设置 → 隐私
2. 选择"管理网站数据"
3. 在搜索字段中输入"openscholar.ai"
4. 选择该条目并选择"移除"

**Microsoft Edge：**
1. 点击右上角的三点菜单（⋯）
2. 进入设置 → Cookie和网站权限 → Cookie和网站数据
3. 选择"查看所有Cookie和网站数据"
4. 搜索"openscholar.ai"
5. 点击删除图标

### 阻止分析Cookie被设置

如果您希望阻止我们创建分析Cookie：

1. **禁用所有Cookie**：将浏览器配置为拒绝所有Cookie（注意：这可能会影响其他网站的运行）
2. **仅阻止第三方Cookie**：这将阻止外部跟踪器，同时允许我们的第一方分析Cookie——这不会阻止openscholar.ai的Cookie
3. **安装隐私浏览器扩展**：Privacy Badger或uBlock Origin等隐私工具可以阻止分析Cookie
4. **启用"请勿跟踪"**：虽然openscholar.ai目前不响应DNT信号，但您可以在浏览器设置中激活此选项
5. **使用我们的Cookie设置**：点击任何openscholar.ai页面底部的"Cookie设置"来调整您的偏好设置
